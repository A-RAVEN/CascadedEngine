# 证据-一致-003：`Select-String 'virtual'` 会数到 10，不是 9

## 主张

`tasks.md` 1.1 的验收命令与期望读数不自洽：design D2 的门面类体有九个纯虚方法，外加一个虚析构 `virtual ~IResourceRegistry() {}`。`Select-String 'virtual'` 按行匹配，会命中 10 行；任务却把期望写死为 9，并只在括号里注明「不含析构」。执行者按字面跑命令会得到 10，验收假红。

## 原文

`openspec/changes/csharp-resource-asset-foundation/tasks.md` 1.1：

> 新建门面头 `Interface/ScriptHost/header/ScriptHost/IResourceRegistry.h`：`CA_BIND()` + 九个纯虚方法（design D2 逐字）……验收：`Test-Path` 为真；`Select-String 'virtual' ` 计数 = 9（不含析构）；`CA_BIND()` 命中 1。

`openspec/changes/csharp-resource-asset-foundation/design.md` D2 的类体：

> virtual ~IResourceRegistry() {}
> virtual void RegisterFactory(castl::string const& typeName, uint64_t factoryHandle) = 0;
> virtual bool HasFactory(castl::string const& typeName) const = 0;
> virtual bool UnregisterFactory(castl::string const& typeName) = 0;
> virtual void CreateResource(castl::string const& typeName, castl::string const& path) = 0;
> virtual bool HasResource(castl::string const& path) const = 0;
> virtual bool ReleaseResource(castl::string const& path) = 0;
> virtual void SerializeAll() = 0;
> virtual castl::string GetResourceRootPath() const = 0;
> virtual castl::string GetResourceFullPath(castl::string const& path) const = 0;

## 实测读数

对 `design.md` 实际执行：

```powershell
(Select-String -LiteralPath 'openspec\changes\csharp-resource-asset-foundation\design.md' -Pattern 'virtual').Count
```

读数为 **10**；逐行输出就是「析构 1 行 + 方法 9 行」。因为 tasks 1.1 要求新头「design D2 逐字」，新头里也会包含这一行虚析构，所以同样的命令在新头上也会得到 10。

## 为什么是 minor

- 设计的方法数没有错：九个纯虚方法在 design D2 里确实是九个，名称与签名也与 spec 对得上。
- 错的只是验收命令和期望读数的对应关系；它会让执行者误以为头文件写错了，或诱导执行者删掉析构/少写一个方法去凑 9——后者会直接破坏 design D2 的「逐字」要求。
- 不阻塞构建与功能，但会阻塞 1.1 的完成判定，属于可当场改掉的判据缺陷。

## 改法

- 方案甲（推荐）：命令显式排除析构：

  ```powershell
  (Select-String -LiteralPath 'Interface\ScriptHost\header\ScriptHost\IResourceRegistry.h' -Pattern 'virtual' |
      Where-Object { $_.Line -notmatch '~IResourceRegistry' }).Count   # 期望 9
  ```

- 方案乙：数纯虚方法结尾：

  ```powershell
  (Select-String -LiteralPath 'Interface\ScriptHost\header\ScriptHost\IResourceRegistry.h' -Pattern '=\s*0;').Count   # 期望 9
  ```

  九个方法都以 `= 0;` 结尾，析构那一行没有。

- 方案丙：保留原命令，把期望读数改成 10，并另加一条「九个 `= 0;`」的判据，避免把「方法数 = 9」与「virtual 行数 = 10」混为一谈。
