# 证据 004：缺失文件的异常类型没有判据，`AssetFormatException` 可以被绕过

对应主张：`主张-验收-004.json`（severity = misleading）
审查对象：`specs/csharp-asset-layer/spec.md` 的 Requirement「资产格式必须带版本且损坏显式失败」+ `tasks.md` 3.4 / 4.2
审查快照：asset-layer spec 14:46:01（SHA-256 `facd8fc714f4938e…`）、`tasks.md` 14:46:34（`859d5f2495379678…`）

## 结论

规范把「魔数不符 / 版本不是 1 / 长度越界 / 文件缺失」统一要求成 `AssetFormatException`，但两处验收只测「抛了没有 + 文本里有没有路径」，没有一处校验异常类型。设计 D6 又直接写 `File.ReadAllBytes`（缺文件时 .NET 抛 `FileNotFoundException`，消息里恰好带路径）。于是「漏包 `AssetFormatException`」的实现能让 3.4 与 4.2 全绿，规范被违反却抓不到。

## 规范原文

`specs/csharp-asset-layer/spec.md:19`：

> C# 资产格式 MUST 含魔数与 formatVersion（本批 = 1），小端逐字段顺序写。解析 MUST 校验魔数、版本、长度边界；**魔数不符 / 版本不是 1 / 长度越界 / 文件缺失 MUST 抛 `AssetFormatException`，消息 MUST 点名路径与原因**，MUST NOT 静默返回空对象或把垃圾灌进资产。

同一文件的场景「缺失文件不静默」（第 31-34 行）却只写：

> - **WHEN** 对磁盘上不存在的路径调 `Load`
> - **THEN** MUST 抛异常点名路径；MUST NOT 注册空资源

场景比 Requirement 弱一档（没有类型），而 5.2 的场景对照是按场景核的 ⇒ 类型这一条在验收里彻底消失。

## 验收原文（都没有类型）

`tasks.md` 3.4：

> 格式解析校验：魔数 / 版本 / 长度边界，失败抛异常不静默。验收：版本改 2、截短一半、缺失文件三条反例各自抛且文本点名（红态读数存 `evidence/3.4-*.txt`）……

`tasks.md` 4.2：

> ……失败面（坏句柄 / 未注册类型 / 损坏版本 / 缺失文件）。验收：……失败面四条断言各自能红……

两处都只要求「抛 + 文本点名」。`catch (FileNotFoundException ex)` 只要把 `ex.Message` 打进失败文本，就能满足「抛且文本点名」。

## 机制：缺文件天然抛别的类型

`design.md` D6（第 93 行）原文：

> `Load(path)`：`HasResource(path)` 为真 → 先 `ReleaseResource(path)`……`GetResourceFullPath(path)` → `File.ReadAllBytes` → 按魔数分派解析 → `Create` → 填数据。文件不存在 → 显式异常。

`System.IO.File.ReadAllBytes` 对不存在的路径抛 `FileNotFoundException`（`IOException` 的子类），消息形如 `Could not find file '<path>'`——「抛异常 + 点名路径」两条都自动满足。要在缺文件时抛 `AssetFormatException`，必须显式 try/catch 再包一层；工件里没有任何一条验收会因此变红。

## 后果

- 实现者按 tasks 3.4 写测试，`Assert.Throws<Exception>` / `catch (Exception)` 都能过；`AssetFormatException` 这个契约没有判据保护。
- 「消息同时含路径与原因」也没判：FileNotFoundException 只带路径，不带「文件不存在」这种原因词（它是英文消息），中文原因词没人核。
- 5.2 的「场景对照」逐条核对 12 条 Requirement 时，如果按场景对（第 31-34 行），这条 Requirement 的原文其实没有被覆盖。

## 建议改法

1. 3.4 与 4.2 的判据改成「类型 + 文本」：四条（魔数 / 版本 / 截短 / 缺失）都必须以 `AssetFormatException` 收口；C# 测试写 `catch (AssetFormatException ex)`，并断言 `ex.Message` 同时含路径与原因关键词。
2. 实现侧把 `File.ReadAllBytes` 包进 try/catch 转成 `AssetFormatException`（其它 `IOException` 同样处理），与 Requirement 对齐。
3. 红态：临时让缺失文件路径直接冒 `FileNotFoundException`，该断言必须红；读数存 `evidence/3.4-缺失文件-红态.txt`。这样才证明「类型判据」不是恒真。
