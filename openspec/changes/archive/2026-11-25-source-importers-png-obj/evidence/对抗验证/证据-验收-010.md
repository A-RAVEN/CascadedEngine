# 证据-验收-010：重导入场景的「落盘字节与源一致」字面不可能

面：④ 门控与管线（重导入）。severity：Blocking。

## 工件原文

- `specs/source-importers-png-obj/spec.md:40-43`：
  > `#### Scenario: 重导入替换为新对象`
  > `- **WHEN** 同一源文件第二轮扫描导入`
  > `- **THEN** 管线 MUST 注册新对象替换旧（旧代理退役），② 落盘字节 MUST 与源一致（确定性导入）`
- `specs/source-importers-png-obj/spec.md:33` 也说「注册/落盘/重导入替换 MUST 由管线（ScanSourceDirectory）做」。

## 源码事实

`Scripting/Managed/Assets/Texture2D.cs:57-69` 的 `Serialize()`：

> `Magic.CopyTo(bytes, 0);`（`CATX`）
> `BinaryPrimitives.WriteUInt32LittleEndian(bytes.AsSpan(4), (uint)FormatVersion);`
> `BinaryPrimitives.WriteInt32LittleEndian(bytes.AsSpan(8), Width);` … `bytes.AsSpan(20), (ulong)pixels.Length`
> `pixels.CopyTo(bytes, HeaderSize);`

`Scripting/Managed/Assets/Mesh.cs:64-78` 的 `Serialize()`：

> `Magic.CopyTo(bytes, 0);`（`CAMH`）
> `BinaryPrimitives.WriteUInt32LittleEndian(bytes.AsSpan(4), (uint)FormatVersion);` … 两个计数、两个长度
> `vertexData.CopyTo(bytes, HeaderSize); indexData.CopyTo(bytes, HeaderSize + vertexData.Length);`

CATX 头部 28 字节（`Texture2D.cs:29`），CAMH 头部 32 字节（`Mesh.cs:36`）；`.tex`/`.mesh` 是「头 + 解码/解析后的载荷」，与 `.png`/`.obj` 源文件字节永远不同。

## 命令与真实输出

```powershell
$h = Select-String -Path 'openspec\changes\source-importers-png-obj\tasks.md' -Pattern '重导入|第二轮|新对象'
if ($h) { $h } else { '无匹配' }
```

真实输出：

```text
无匹配
```

tasks 里没有第二轮扫描、没有「新对象/旧代理退役」断言、也没有「两轮字节一致」断言。

## 结论

「② 落盘字节 MUST 与源一致」对转换器是恒假命题：PNG 源字节不可能等于 CATX 字节，OBJ 文本不可能等于 CAMH 字节。这个场景要么永远红，要么只能被解释成「与第一轮产物一致」——但工件没这么写。并且该场景在 tasks 里完全没有对应任务，连「第二轮扫描」都不会发生。需要把断言改成「第二轮落盘字节与第一轮/写死 CATX·CAMH 期望逐字节相同（确定性导入）」，并加第二轮扫描 + 新对象 + 旧句柄 1001 的验收。
