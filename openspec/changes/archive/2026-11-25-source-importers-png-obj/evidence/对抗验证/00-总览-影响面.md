## 三、次级发现（未计 claim，父 agent 可决定是否升级）

1. **新门控会让 `check_csharp_host_readme.py` 变红**：该脚本把 `Host.cs` 里读到的每个 `CASCADED_*` 与 `CSharpHost/README.md` 环境变量表比对；工件没有 README 登记任务，4.1 也不跑这个脚本。归档 `editor-web-render-spike` 有同款先例与补法。详见 `证据-影响-000-其余检查.md` 二节。
2. **默认关零行为**：4.1 只比 name+status（基线 JSON 四字段），日志/LastError/静态状态差异不可见；3.1 的「门控关零行为」没有测量方法。
3. **3.1 的 Parse 读回**：`Texture2D.Parse` / `Mesh.Parse` 都是 `internal`，C++ tester 无入口；现有 `TestCSharpAssets` 走 C# 读数 + C++ 原始字节对照，3.1 没写读数通道。
4. **默认 ① 源目录不存在**：`仓库根/SourceAssets` 当前 `Test-Path` = `False`；不设 `CASCADED_SOURCE_IMPORTERS_DIR` 时「门控开」没有任何产出（仓库里真实 PNG 在 `CAResources/Images/` 下，不在默认源目录）。
5. **全量名单**：run-all 是 `Main.cpp` 里硬编码的 22 条；3.1 只写「独立进程」，没写「只进 --list、不进全量同进程顺序跑」（归档 spike 任务明写过这一条）。若加进全量，会与 `主张-影响-002` 的 shLib/CAAssets 波及叠加。
