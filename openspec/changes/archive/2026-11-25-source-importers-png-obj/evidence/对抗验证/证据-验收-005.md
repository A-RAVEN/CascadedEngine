# 证据-验收-005：规范列出的 MUST 拒绝分支没有红态

面：③ 红态与异常可观测性。severity：Blocking。

## 工件原文

- `specs/source-importers-png-obj/spec.md:5`：「不支持的 PNG（16 位/隔行/调色板）MUST 抛 AssetFormatException 点名，MUST NOT 静默。」
- `specs/source-importers-png-obj/spec.md:19`：「缺顶点/索引越界/空网格 MUST 抛 AssetFormatException 点名。」
- `tasks.md:9` 的验收：「构建过；已知 PNG 夹具解码像素==写死期望（五种滤波各覆盖一例）；坏 PNG（错签名/截断）抛 AssetFormatException（evidence/1.1-*.txt）。」
- `tasks.md:10` 的验收：「构建过；已知 OBJ（立方体 8 顶点 12 三角）解析顶点/索引==写死期望；坏 OBJ 红态（evidence/1.2-*.txt）。」
- `tasks.md:20` 的红态：「坏 PNG/坏 OBJ→AssetFormatException 点名」。
- `design.md:45`：「坏 PNG（截断/错签名）/坏 OBJ（索引越界）→ AssetFormatException 点名」。

## 命令与真实输出

```powershell
Select-String -Path 'openspec\changes\source-importers-png-obj\tasks.md' -Pattern '16 位|隔行|调色板|缺顶点|空网格|错签名|截断|索引越界'
```

真实输出（只保留行号与命中位置）：

```text
tasks.md:9: ……16 位/隔行/调色板抛 AssetFormatException 点名。验收：……坏 PNG（错签名/截断）抛 AssetFormatException……
tasks.md:10: ……缺顶点/索引越界/空网格抛 AssetFormatException。验收：……坏 OBJ 红态（evidence/1.2-*.txt）。
```

这两行里，`16 位/隔行/调色板`、`缺顶点/空网格` 都只出现在**实现描述**中；验收段只落 `错签名/截断` 和笼统的「坏 OBJ 红态」。design D6 的红态清单只有 `截断/错签名` 与 `索引越界`。

## 结论

五类 MUST 拒绝分支（16 位、隔行、调色板、缺顶点、空网格）没有夹具、没有期望错误文本、也没有红态条目。实现可以完全不写这些判断，`TestSourceImporters` 仍然全绿——规范里最容易被忽略的「显式拒绝」正好没有被验收覆盖。
