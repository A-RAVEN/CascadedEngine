## 二、缺陷：工厂路径缺注册来源

### 1. `AssetDatabase.Create` 依赖已注册的工厂

```csharp
// Scripting/Managed/Assets/AssetDatabase.cs:32-36
public ResourceBase Create(string typeName, string path)
{
    m_registry.CreateResource(typeName, path);
    return AssetFactoryBase.Dequeue(typeName);
}
```

`Create` 只负责「门面新建 + 出队」，**不填数据**；填数据由调用方做（`ResourceAssetProbe.cs:287-305` 就是 `s_database.Create(...)` 之后逐字段赋值的样例）。

### 2. 全仓唯一的工厂注册点在门控探针里

```csharp
// Scripting/Managed/ResourceAssetProbe.cs:262-271
private static void RegisterFactories()
{
    var textureFactory = new Texture2DFactory();
    ulong textureHandle = IResourceFactoryBindings.Create(textureFactory);
    s_registry.RegisterFactory(Texture2DFactory.TypeName, textureHandle);
    var meshFactory = new MeshFactory();
    ulong meshHandle = IResourceFactoryBindings.Create(meshFactory);
    s_registry.RegisterFactory(MeshFactory.TypeName, meshHandle);
    ...
}
```

门控：

```csharp
// ResourceAssetProbe.cs:56-57
internal static bool Enabled =>
    Environment.GetEnvironmentVariable(ProbeVariable) == "1";   // ProbeVariable = "CASCADED_CSHARP_ASSET_PROBE"（:27）

// Host.cs:334-337

```

```powershell

# 命中仅：ResourceAssetProbe.cs 的 268 / 271 / 274 / 363 / 370
```

也就是说：不开 `CASCADED_CSHARP_ASSET_PROBE=1`，`Texture2D` / `Mesh` 两个工厂从来没有注册过。

### 3. 导入器自己又不能注册工厂

> design.md:24
> - `Produce` 扫源目录对应扩展名文件，逐个解码/解析造资产，入 `ResourceImporterProductionsBase` 迭代器（NextPath=② 相对路径如 `Textures/foo.tex`/`Meshes/bar.mesh`，NextResource=Texture2D/Mesh）。**导入器不调注册表**（grep 五写入口 0）。

即使把 `RegisterFactory` 视为「注册表调用」之外的动作，design 的「导入器不调注册表」与 spec 要求 3 的「导入器 MUST NOT 调注册表」也把这条路堵死。

### 4. 工件没有“注册工厂”的任务

`tasks.md` 的任务只有 1.1 / 1.2 / 2.1 / 2.2 / 2.3 / 3.1 / 3.2 / 4.1 / 4.2；没有一条要求注册这两个工厂。D4 的首选路径（经工厂）与验收（2.3「门控开导入→② 落盘 + HasResource 真」）之间因此缺一环。

## 三、为什么不判 blocking

design D4 同时给了第二条路：

> design.md:36
> ……（经 Texture2DFactory/MeshFactory 的 Create 入队 + AssetDatabase 出队填数据，沿用 csharp-resource-asset-foundation D4/D5 模式；**或直接 new 资产填数据交迭代器，由管线 CreateProxy 注册**）。

「直接 new」这条路是真实可行的：`TestCSharpImporter` 已经证明 C# 的 `ResourceBase` 子类可以经 `NextResource()` → 生成代理 `CreateProxy` → 管线 `shared_ptr(ptr, delete)` → `RegisterResource`（`Main.cpp:8881-8887`、`ResourceImporterProbe.cs:105-120`）。执行者可以绕开工厂。因此本条是 misleading（首选路径踩空 / 措辞不准确），不是 blocking。

## 四、修法（建议）

- 选「直接 new」：删掉 D4 里「经 Texture2DFactory/MeshFactory + AssetDatabase」的措辞（或把它标成“不采用”），避免执行者按首选路径踩空。
- 选工厂：新增任务——门控打开时由 Host（导入器之外，例如 `Host.Tick` 的独立分支）注册 `Texture2DFactory` / `MeshFactory`；2.3 验收加读数「`HasFactory(\"Texture2D\")` / `HasFactory(\"Mesh\")` 为真」；并把 D4「AssetDatabase 出队填数据」改成「AssetDatabase.Create 出队，导入器填数据」。
