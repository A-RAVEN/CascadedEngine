# csharp-bindings 增量

## MODIFIED Requirements

### Requirement: 跨头文件接口投影必须有构建期已知接口清单
`build.py` SHALL 先通过 `CodeGen.exe --list-bind-interfaces` 从每个主头实际 `CA_BIND` 形状收集 `<短名>=<完整限定名>`，聚合后通过重复的 `--known-interface <短名>=<完整限定名>` 传给正式生成。`CODEGEN_BINDINGS` 的期望产物清单只用于产物存在性检查，且 MUST 按**精确文件名**核对（每个 stem 期望 `<stem>.Bindings.cs` / `<stem>.Bindings.cpp` 中的哪些，以开工清点出的该 stem 实际产物形状为准），MUST NOT 用前缀通配（`<stem>.Bindings.*` 会放行 `.redbak` 这类改名件，闸门恒绿），MUST NOT 被当作完整接口清单。已知清单 MUST 只用于类型投影和诊断，不得让未在主头文件标注的接口额外生成产物。

跨头文件返回抽象接口时，目标接口的完整限定名 MUST 在已知清单中，否则生成器 MUST 非零退出并说明缺少哪个目标。非接口数据对象的智能指针返回可以继续只提供原生发行者句柄，但不得因此生成伪造的公开 C# 资源对象。共享公开类型与接口的身份 MUST 以完整限定名为准（短名只作显示名）；两个不同 C++ 类型映射到同一 C# 全名（命名空间镜像路径 + 类名）MUST 非零退出并点名冲突双方，不得只凭短名或部分限定名猜测目标（例：`AB::Widget` 与 `Ab::Widget` 都映射为 `Ab.Widget`，必拒；`a_b::Widget` 与 `a::b::Widget` 分别映射 `AB.Widget`/`A.B.Widget`——`::` 分层、`_` 层内分段拼接——合法共存）。

#### Scenario: 分头生成的发行接口与资源接口能够组合
- **WHEN** 资源接口和发行接口位于不同头文件，构建清单包含双方并分别运行生成器
- **THEN** 发行接口的公开 C# 方法 MUST 返回目标资源表面对象，目标接口的函数表 MUST 能解析和释放返回句柄，托管构建不得缺少目标类型

#### Scenario: 清单来自实际标记而非部分期望产物
- **WHEN** 一个输入头包含多个 `CA_BIND` 接口，而 `CODEGEN_BINDINGS` 的期望产物清单只列其中一部分
- **THEN** 收集清单 MUST 仍包含全部实际标记接口及其完整限定名，既有跨接口返回不得因未列入期望清单而被判未登记

#### Scenario: 跨命名空间同名接口各自成面
- **WHEN** 两个命名空间中存在同短名接口（如 `ns1::Device` 与 `ns2::Device`），都被标注进同一构建
- **THEN** 两者 MUST 各自生成到自己的镜像命名空间、各自经 `--update-ids` 追加发号入登记表（既有锁行一字不动），构建 MUST 全绿——MUST NOT 以同短名为由拒绝（用户 2026-11-09 裁定：拒绝跨命名空间同名等于牺牲 C++ 接口易用性）

#### Scenario: 映射后全名冲突必须拒绝
- **WHEN** 两个不同的 C++ 类型经命名空间镜像映射后得到同一 C# 全名（如 `AB::Widget` 与 `Ab::Widget` 都映射为 `Ab.Widget`），或已知清单条目与返回目标的完整限定名不一致
- **THEN** 生成或清单聚合 MUST 非零退出并点名冲突双方的完整限定名，MUST NOT 只凭短名选择目标接口

#### Scenario: 未登记抽象接口不得生成悬空公开类型
- **WHEN** 一条跨头文件方法返回一个具有纯虚方法、但不在构建期已知清单中的接口
- **THEN** 生成器 MUST 非零退出并点名目标接口与缺失清单，不得留下引用不存在 C# 类型的产物

#### Scenario: 改名件必须被产物闸门自己点名拒绝
- **WHEN** 期望产物检查时，某接口的期望产物在产物目录中缺失、只剩其改名件（如 `<stem>.Bindings.cpp` 不在而 `<stem>.Bindings.cpp.redbak` 在；构造该状态的手段见 design D5——生成段会无条件重写产物，红态须从源码侧令本次构建不再生成该产物）
- **THEN** 构建 MUST 失败，且**期望产物闸门自己的消息**（「缺少这些接口的产物」）MUST 点名该 stem——MUST NOT 只靠下游 check_bindings 兜底而闸门放行；状态还原后构建 MUST 全绿
