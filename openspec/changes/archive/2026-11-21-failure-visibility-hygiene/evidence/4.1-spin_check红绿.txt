==================================================================

(a) 零个 / 多个活跃 change（本 change 活跃期间无法安全构造）：
源码（Tools/spin_check.py 的 resolve_change_dir 末尾）：
    names = active_change_names()
    if len(names) == 1:
        return CHANGES / names[0]
    if not names:
        raise ChangeLookupError("当前没有活跃 change；请用 --change <名> 显式指定（已归档 change 也可）")
    raise ChangeLookupError(f"当前有 {len(names)} 个活跃 change（{', '.join(names)}）；"
                            f"请用 --change <名> 显式指定")
main 里捕获 ChangeLookupError → print(message) → return 2。三条分支都非零退出，不放行。

(b) 归档名多匹配（归档里没有任何两个目录能被同一后缀同时匹配；实测命令与输出）：
[命令] 归档目录去掉日期前缀后 Group-Object 查重 + 两两 EndsWith("-" + <名>) 检查
[输出] 无（该分支需造目录才能实测，走读证明）
源码：
    matches = sorted(p for p in ARCHIVE.iterdir()
                     if p.is_dir() and p.name.endswith("-" + explicit))
    if len(matches) == 1:
        return matches[0]
    if len(matches) > 1:
        raise ChangeLookupError(
            f"change 名 {explicit} 在归档里匹配到多个：{', '.join(p.name for p in matches)}"
            f"；请改用完整目录名（--change <目录名>）")
main 同样返回 2。

(c) `openspec` 命令形态（实测修正，记录在此以免下次踩坑）：本机 PATH 上的 `openspec` 是 npm shim
（`openspec` 为 Unix shell 脚本、`openspec.cmd` 才是 Windows 可启动形式）。subprocess 的 CreateProcess
既不补 PATHEXT 也不跑 .cmd —— 裸 `["openspec", ...]` 实测抛 WinError 2。现实现用 `shutil.which("openspec")`
定位，`.cmd/.bat` 经 `cmd.exe /c` 启动；绿态 ③/④ 即该实现的实测读数。
