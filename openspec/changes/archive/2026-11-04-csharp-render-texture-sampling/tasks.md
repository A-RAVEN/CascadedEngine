# csharp-render-texture-sampling 实施任务

用户故事：

- **US1**：C# 渲染调用方需要用纹理+采样器驱动着色输出（数据走贴图而非顶点/常量），并能在调用当场得到点名的拒绝。
- **US2**：引擎维护者需要非法尺寸、非法字节、表外字段、空纹理、漏绑在适配层挡下，绝不进入两后端"未知字段静默跳过 / 越界 `CA_ASSERT` / 非法参数构造"路径；"释放后使用"由托管表面对象层的 `ObjectDisposedException` 防线兜住。
- **US3**：渲染验证人员需要两个后端的真实像素证据证明**纹理字节经采样进入输出**（而非 UV 插值假象），且漏绑、改纹理、错字节都会让判据失败。

日志与文本记录统一写入 `openspec/changes/csharp-render-texture-sampling/evidence/`；运行期产物（`test_output/*.log|*.png|*.json`）留在 `test_output/`（gitignore），由 `Tools/check_csharp_texture_sampling.py` 校验，关键读数同时抄入 evidence。红态证据只追加不覆盖。**分工**：`GPUBackendTester.exe` 一切运行（含 `--list`、`--headless`、负向开关、位置变异）由主 agent 代跑——执行者备好命令上报、取回读数入证据后再勾；CoreTests 与 `python Tools/*.py`、`python Tools/CodeGen/*.py` 由执行者自跑；构建只走 `python build.py`。
