# 证据-存在-001：`Scripting.Managed.dll` 的源不止 `Scripting/` 下 38 个 .cs

对应主张：`主张-存在-001.json`（severity=blocking）。全部只读命令，未跑构建、未跑 tester、未改工件。

## 一、计数：手写源 38 份

```powershell
(Get-ChildItem -Path Scripting -Recurse -File -Filter *.cs | Measure-Object).Count   # → 38
Get-ChildItem -Path Scripting -Recurse -File -Filter *.cs | Group-Object { ... 顶层目录 }  # → Managed: 38
Get-ChildItem -Path Scripting -Directory | Select-Object -ExpandProperty Name          # → Managed（只有一个子目录）
```

## 二、csproj 原文：生成绑定源也被 Compile 进来

`Scripting/Managed/Scripting.Managed.csproj`（逐字引文，行号为便于核对）：

```xml
L40: <CascadedBindingDir Condition="'$(CascadedBindingDir)' == ''">$(MSBuildThisFileDirectory)..\..\out\build\x64-debug\codegen\bindings</CascadedBindingDir>
...
L44: <CascadedBindingFile Include="$(CascadedBindingDir)\*.Bindings.cs" />
...
L50: <Error Condition="'@(CascadedBindingFile)' == ''"
L51:        Text="$(CascadedBindingDir) 里没有任何 *.Bindings.cs —— 绑定没有生成，托管侧不能凭空编译" />
...
L56: <Compile Include="@(CascadedBindingFile)" />
```

L56 就是「这些生成绑定源是同一个程序集的编译输入」的直接证据；L51 的报错文本从反面确认（没有生成绑定源就编不出托管侧）。

## 三、计数：生成绑定源 129 份

```powershell
(Get-ChildItem -Path out\build\x64-debug\codegen\bindings -Recurse -File -Filter '*.Bindings.cs' | Measure-Object).Count  # → 129
(Get-ChildItem -Path out\build\x64-debug\codegen\bindings -Recurse -File -Filter '*.cs' | Measure-Object).Count            # → 129（该目录所有 .cs 都是 *.Bindings.cs）
```

例（前 5 个）：`a_b__Widget.Bindings.cs`、`a__b__Widget.Bindings.cs`、`cawindow__FloatRect.Bindings.cs`、`cawindow__IWindow.Bindings.cs`、`cawindow__IWindowSystem.Bindings.cs`。

合计编译输入 = 38 + 129 = **167 份 .cs**，全部编进同一个 `Scripting.Managed.dll`。

## 四、产物位置与工件描述一致（这一半是好的）

```powershell
Get-ChildItem -Path out -Recurse -File -Filter 'Scripting.Managed.dll'
# → out\build\x64-debug\bin\Scripting.Managed.dll
# → out\build\x64-debug\managed\Scripting.Managed.dll
Get-ChildItem -Path CAAssets -Recurse -File -Filter '*.dll'   # → 空（dll 不在 CAAssets，与 design「不在 CAAssets」一致）
```

## 五、工件对生成绑定源零提及

```powershell
Select-String -Path design.md,tasks.md,specs\...\spec.md -Pattern 'Bindings.cs|codegen|生成绑定'
# → 0 命中
```

## 六、结论与影响

`design.md:9` 的「由 `Scripting/` 下 **38 个 .cs** 编译来」把程序集的源集写小了 129 份。照 spec.md:33 的「扫 `Scripting/` 递归 `*.cs`」实现，这 129 份真被编译进 dll 的源文件在 dll 条目被隐去后**永远不会出现在资产浏览器里**，工件既没说略去了什么，也没给取回办法（= 静默降级）。而 tasks.md:21 的「源条目数 == 源文件数」两侧都量 `Scripting/`，在这一缺陷仍在时照样通过（= 假绿），所以不能靠这条验收发现。
