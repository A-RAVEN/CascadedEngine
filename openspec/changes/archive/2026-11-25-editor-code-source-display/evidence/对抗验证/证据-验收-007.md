# 证据-验收-007：「提供者未注册」红态不可构造

## 1. 工件要求（逐字引文）

- tasks.md 3.1：「红态：源根空→源条目空不报错；**提供者未注册→落默认 shLib 仍显**（证注册真生效，非恒隐）。验收：--list 含 TestCodeSourceDisplay、全量仍 22；独立进程过；红态各能红（evidence/3.1-*.txt）。」
- design.md 验收节：「红态：源根空 → 源条目空（不报错）；提供者未注册 → 落默认（shLib 仍显，证注册真生效）。」

## 2. 注册面没有注销入口（命令 + 真实输出）

```powershell
Select-String -Path 'Scripting/Managed/Editor/AssetDisplay.cs' -Pattern 'internal static (void|IDisplayProvider)|s_providers' | ForEach-Object { $_.LineNumber.ToString() + ': ' + $_.Line.Trim() }
```

真实输出：

```text
103: private static readonly Dictionary<string, IDisplayProvider> s_providers =
117: internal static void Register(string kind, IDisplayProvider provider)
123: s_providers[kind] = provider;
127: internal static IDisplayProvider Resolve(string kind)
129: if (!string.IsNullOrEmpty(kind) && s_providers.TryGetValue(kind, out IDisplayProvider provider))
```

只有 Register / Resolve；注释原文：「按种类登记提供者（v2 的程序集 / 缩略图提供者从这里注册；同种类再登记 = 替换）」。没有 Unregister / 复位。

## 3. 全仓库没有源显示开关（命令 + 真实输出）

```powershell
git grep -n -E 'SOURCE_DISPLAY|DISPLAY_PROVIDER|SourceDisplay' -- '*.cs' '*.cpp' '*.h' '*.md'
```

真实输出：空（零命中）。

托管侧现有自检开关（`git grep -n 'CASCADED_EDITOR_SELFTEST' -- 'Scripting'` 的取值面）：`no-runtime`、`no-dock-controller`、`no-facade`、`capture-dock=<png>`；另有 `CASCADED_EDITOR_STOP` / `CASCADED_EDITOR_READINGS_FILE`。没有与显示提供者注册相关的开关。

`CSharpHost/README.md` 原文：「`CASCADED_EDITOR_SELFTEST=no-facade`（跳过资源注册表门面绑定 → `list-assets` 必回 `E_ASSET_ROOT`，供资产浏览失败面用；**不限 Debug**）……」。

## 4. 编辑器服务一次性（逐字引文）

`Test/GPUBackendTester/Main.cpp`：

```text
// **独立进程用例（design D8）**：`EditorService` 是进程级一次性状态机（`Shutdown` 把状态落 4、没有
// 复位路径），而 `TestEditorWindowPanel` 收尾会用 `CASCADED_EDITOR_STOP=1` 停服务 —— 两个编辑器用例在
// 同一进程里不能共存。所以本用例**不进全量同进程顺序跑**（`--list` 仍列 23 行），只按
// `GPUBackendTester.exe --test TestEditorAssetBrowser` 独立进程跑。
```

tester 只能经 WebSocket 发 `list-assets` 读结果，不能操作托管侧静态表。

## 5. 结论

「未注册」状态在产品代码里不存在（注册是无条件的），tester 也没有开关能让它不注册；不新增 seam 就无法构造该红态。按现工件执行，这条红态只能被省略或被记成「代码走读」——两者都不是能失败的验收。
