# 证据-验收-002：「dll 条目不出现」恒真

## 1. dll 不在资产根、资产根枚举只枚举 CAAssets（命令 + 真实输出）

```powershell
Get-ChildItem 'CAAssets' -Recurse -File | ForEach-Object { $_.FullName.Replace((Get-Location).Path + '\','').Replace('\','/') + '  ' + $_.Length }
```

真实输出（全部 5 条，无任何 .dll）：

```text
CAAssets/D3D12ShaderLibrary.shLib  293737
CAAssets/VulkanShaderLibrary.shLib  145710
CAAssets/CSharpProbe/Contrast.res  4
CAAssets/CSharpProbe/Imported_A.res  2
CAAssets/CSharpProbe/Imported_B.res  2
```

```powershell
Select-String -Path 'Scripting/Managed/Editor/EditorService.cs' -Pattern 'foreach \(string file in Directory.EnumerateFiles' | ForEach-Object { $_.LineNumber.ToString() + ': ' + $_.Line.Trim() }
```

真实输出：

```text
1100: foreach (string file in Directory.EnumerateFiles(root, "*", SearchOption.AllDirectories))
```

## 2. 种类映射没有 .dll（命令 + 真实输出）

```powershell
Select-String -Path 'Scripting/Managed/Editor/AssetDisplay.cs' -Pattern '\["\.' | ForEach-Object { $_.LineNumber.ToString() + ': ' + $_.Line.Trim() }
```

真实输出：

```text
110: [".shlib"] = "shader-library",
111: [".tex"] = "texture",
112: [".mesh"] = "mesh",
113: [".res"] = "resource",
```

代码注释原文：「未知扩展名落 `file` 种类而不是报错」。因此放进 CAAssets 的 `.dll` 会走默认提供者产一条 `kind=file` 条目（这是代码路径推导，非实测：本轮禁跑 tester）。

## 3. 工件自己的两条口径（逐字引文）

- design.md：「C# 程序集 `Scripting.Managed.dll` 在 `out/build/<preset>/bin/`（**不在 CAAssets**）」
- specs/editor-code-source-display/spec.md：「结果 MUST NOT 含 dll 条目；MUST 含每个 .cs 源条目，path/kind=csharp-source/sizeBytes 逐条等于写死期望；dll 不在 CAAssets 也 MUST 引入源条目」
- proposal.md：「list-assets 收集「资产根文件枚举条目」+「注册显示资源条目」，代码型程序集隐去、源文件显现」

## 4. 结论

「dll 条目」只可能由 C# 提供者自己合成；若注册显示资源整段缺失，列表里本来就不会有任何 dll 条目 ⇒「dll 条目不出现」恒真。而资产根内真的出现 dll 时（proposal 的「代码型程序集隐去」按字面应覆盖），现有设计既不隐去也不验收。
