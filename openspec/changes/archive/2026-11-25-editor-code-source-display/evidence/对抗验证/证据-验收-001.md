# 证据-验收-001：新增源条目与生效规范「只列资源根」互斥

## 1. 生效规范的硬口径（命令 + 真实输出）

```powershell
Select-String -Path 'openspec/specs/editor-asset-browser/spec.md' -Pattern '列出资源根|相对资源根路径|VulkanShaderLibrary.shLib' | ForEach-Object { $_.LineNumber.ToString() + ': ' + $_.Line }
```

真实输出（节选）：

- `11: 编辑器 MUST 有**底部通栏独立资产浏览器 dock**（…），列出资源根（门面 `GetResourceRootPath`）下的编辑器资产文件，每行 MUST 含相对路径 / 种类（扩展名映射）/ 大小（字节）/ 修改时间 / 是否已注册（门面 `HasResource`）。…`
- `16: - **THEN** 返回条目 MUST 与真实文件逐条一致（path/nodeId/sizeBytes/kind/modifiedUtc/registered/children 七项）；nodeId MUST = path = 相对资源根路径；children MUST 空；modifiedUtc MUST ISO 8601 UTC；sizeBytes MUST 等于 FileInfo 实测字节；registered MUST 等于 HasResource 读数且**真值与假值都出现**（恒假实现不得过）`

## 2. 增量 spec 只覆盖一条需求

```powershell
Select-String -Path 'openspec/changes/editor-code-source-display/specs/editor-asset-browser/spec.md' -Pattern '^## |^### Requirement' | ForEach-Object { $_.LineNumber.ToString() + ': ' + $_.Line }
```

真实输出：

- `1: ## MODIFIED Requirements`
- `3: ### Requirement: 显示提供者必须资产中心且按种类注册，核心资源接口不动`

没有「底部通栏 dock」需求的 MODIFIED 段，也没有视觉验收需求的 MODIFIED 段（视觉问题见主张-验收-013）。

## 3. 新规范的源条目口径（命令 + 真实输出）

```powershell
Select-String -Path 'openspec/changes/editor-code-source-display/specs/editor-code-source-display/spec.md' -Pattern '相对工程根|MUST NOT 产 shLib|MUST NOT 产 dll' | ForEach-Object { $_.LineNumber.ToString() + ': ' + $_.Line }
```

真实输出（节选）：

- `19: MUST 有 `ShaderSourceDisplayProvider`（kind=shader-library），`Describe(shLib 上下文)` MUST NOT 产 shLib 自身条目，MUST 扫源目录（默认 `CAResources/Shaders`…）递归 `*.slang` 产每个源文件一条 `AssetEntry`（kind=shader-source，path/nodeId=相对工程根源路径，…）…`
- `33: …该提供者 MUST NOT 产 dll 条目，MUST 扫 `Scripting/`（env `CASCADED_EDITOR_CSHARP_SOURCE_ROOT` 可配）递归 `*.cs` 产每个源文件一条（kind=csharp-source，path/nodeId=相对工程根源路径，registered=true 当程序集存在）…`

## 4. 现状代码证明条目只来自资源根枚举

```powershell
Select-String -Path 'Scripting/Managed/Editor/EditorService.cs' -Pattern 'foreach \(string file in Directory.EnumerateFiles|AssetDisplayProviders.Resolve\(kind\).Describe|string.CompareOrdinal' | ForEach-Object { $_.LineNumber.ToString() + ': ' + $_.Line.Trim() }
```

真实输出：

- `1100: foreach (string file in Directory.EnumerateFiles(root, "*", SearchOption.AllDirectories))`
- `1124: IReadOnlyList<AssetEntry> described = AssetDisplayProviders.Resolve(kind).Describe(context);`
- `1133: entries.Sort((left, right) => string.CompareOrdinal(left.Path, right.Path));`

其中 `root` 来自 `registry.GetResourceRootPath()`（同一函数内 `string root = registry.GetResourceRootPath();`），即 CAAssets；源条目来自 CAAssets 之外的 `CAResources/Shaders`、`Scripting`。

## 5. 结构校验通过不代表语义不矛盾

```powershell
openspec validate editor-code-source-display --strict
```

真实输出：

```text
Change 'editor-code-source-display' is valid
```

`openspec validate` 只校验结构，不会发现「同一条生效规范要求两种互斥的 path 口径」。
