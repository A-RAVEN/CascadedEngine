# 证据-溯源-006：导入器扫描根是 CAResources（上一级），不是 CAResources/Shaders

> 定位以逐字引文为准；行号是 2026-11-25 审查时实测值。

## 一、主张摘要

- 主张编号：主张-溯源-006（面④ 源根约定）
- 攻击面：无中生有
- 严重度：misleading
- 工件：`design.md:52`、`design.md:34`
- 一句话：`CAResources/Shaders` 与 `Scripting` 都存在，但 shader 导入器的扫描根是 `CAResources`，所以「与 ShaderImporter 扫描根一致」不成立；今天文件集合恰好相同，靠的是「Shaders 之外没有 .slang」这个巧合。

## 二、工件原文

`design.md:52`：

> 约定假定 shLib←CAResources/Shaders 全部 .slang，与 ShaderImporter 扫描根一致。

`design.md:34`：

> 源根默认：shader＝`CAResources/Shaders`、C#＝`Scripting`（相对工程根）。

## 三、命令与真实输出

```powershell
PS> Test-Path CAResources\Shaders   # True
PS> Test-Path Scripting             # True
PS> Get-ChildItem CAResources
Images / Models / Shaders（三个目录）
PS> (Get-ChildItem CAResources -Recurse -Filter *.slang -File).Count
16
PS> (Get-ChildItem CAResources -Recurse -Filter *.slang -File | Where-Object { $_.FullName -notmatch '\\Shaders\\' }).Count
0
```

导入器读的是 `GetScanSourceDirectory()`（`ShaderImporter_Vulkan.cpp:310`），并递归扫该根（`:336` `recursive_directory_iterator(effectiveSourcePath)`，`:341` 只收 `.slang`）。两根的实际来源：

`VulkanRenderBackendNew/private/RenderBackend_Vulkan.cpp:208-210`：

```cpp
if (std::filesystem::exists(p / "CAResources"))
{
    m_ShaderImporter.SetSourceDirectory(p / "CAResources");
```

`Test/GPUBackendTester/Main.cpp:11850`（赋值）与 `:11943`（调用）：

```cpp
// :11850
ctx.resourcePath = (rootPath / "CAResources").string();
// :11943
ctx.pImportingSystem->ScanSourceDirectory(ctx.resourcePath);
```

也就是说扫描根 = `CAResources`（Shaders 的上一级），不是 `CAResources/Shaders`。

## 四、结论与建议

- 「源根存在」属实；「与 ShaderImporter 扫描根一致」不属实：根路径差一级。今天 16 份 .slang 全在 `Shaders/` 下、外部 0 份，所以两边文件集合相同；但这是环境事实，不是设计保证。
- 后果：任何放到 `CAResources/Images` 或 `CAResources/Models` 的 `.slang` 会被导入器编译进 shLib，而按 design 只扫 `CAResources/Shaders` 的提供者会静默漏掉它（见主张-溯源-010 的静默降级面）。
- 建议：design 改成「扫描根 = `CAResources`（与导入器一致），默认显示根 = `CAResources/Shaders`」，并加一条断言：`CAResources` 递归 .slang 集合 == 显示根递归 .slang 集合，否则显式告警。

## 五、边界

- 核了：目录存在性、16 份全在 Shaders、导入器根/回退根/扫描实现、测试管线传入的根。
- 没核：没有启动引擎或 tester 观察实际扫描日志（只读环境，不跑程序）；生产路径是否只有 Vulkan 回退这一处设置扫描根，未穷举所有后端的初始化路径（D3D12 未见 SetSourceDirectory，依赖管线传入；测试里传的也是 CAResources）。
