## 4. tester 只能看 list-assets 结果（逐字引文）

`Test/GPUBackendTester/Main.cpp`（TestEditorAssetBrowser 用例）：「C++ 侧 WebSocket 发 list-assets…」（PROTOCOL 命令面）；托管侧 `AssetDisplayProviders` 是 `internal static class`，`Resolve`/`Register` 不对外暴露，tester 不能直接调用，也无法读登记表内容。

## 5. 结论

「写死两路径断言」「登记表可查」在现有测试设施里没有宿主：既不能由 C++ tester 观察，也没有 C# 测试工程。除非新增落点，这两条只能退化为代码走读（恒真）。
