# 证据-溯源-010：藏掉程序集 + 源根缺失只回空列表 = 三件静默降级

> 定位以逐字引文为准；行号是 2026-11-25 审查时实测值。

## 一、主张摘要

- 主张编号：主张-溯源-010（面⑥ 静默降级）
- 攻击面：无中生有
- 严重度：blocking
- 工件：`design.md:28`、`design.md:34`、`spec.md:26-29`、`tasks.md:21`
- 一句话：程序集条目无条件隐藏；源根不存在/空时只回 ok=true 空列表；没有标记、没有说略去了什么、没有恢复路径。

## 二、工件原文

`design.md:28`：

> `Describe(shLib 上下文)` **不产 shLib 条目**，改扫源目录 `CAResources/Shaders/`（递归 *.slang）产每个源文件一条

`design.md:34`：

> 源根不存在/空 → 提供者产空条目列表（不报错，浏览器不该整体失败，照 editor-asset-browser 未知扩展名落 file 的容错）

`spec.md:26-29`：

> **WHEN** 源根不存在或无 .slang
> **THEN** 提供者 MUST 产空列表（list-assets ok=true，源条目空），MUST NOT 报错或整体失败

## 三、对照：现有失败通道不是这样

`EditorService.cs:1065-1069`（现有 list-assets 失败路径）：

```csharp
private static void FailListAssets(EditorClient client, EditorCommand command, string message)
{
    Enqueue(client, EditorProtocol.BuildError(command.RequestId, EditorProtocol.ErrorAssetRoot, message));
    Host.LogFromEditor("[编辑器] list-assets 失败（requestId=" + command.RequestId + "）：" + Sanitize(message));
}
```

现有语义：根不可用（空串 / 目录不存在 / 非法 / 无权限 / 门面错）一律 `E_ASSET_ROOT` 显式失败；只有「目录存在但没文件」才是 ok=true 空数组（已生效 spec:11：「目录存在但无文件 = 合法空态（ok=true 空数组）；门面失败 / 根非法 / 枚举 IO 错误 MUST 显式 E_ASSET_ROOT，MUST NOT 用 ok 空数组冒充成功」）。

design 把「源根不存在」也归进 ok 空态，等于把一种配置错误伪装成合法空态；同时 shLib/dll 条目被隐藏，用户连「这里本来有个程序集」的最后线索也没有。

## 四、三件静默降级逐条对照（AGENTS §9）

| 要求 | 本设计 |
|---|---|
| 有没有标记 | 没有：不报错、无日志要求、条目里无任何「源根缺失」字段 |
| 标记里有没有说清略去了什么 | 没有：被隐藏的是 shLib/dll 程序集条目本身，用户看不到「略去了哪个程序集、因为哪个根没找到」 |
| 调用方能不能取回完整内容 | 不能：没有 env 提示、没有错误文本、没有「显示程序集条目」的开关；只能猜是源根配错 |
| 可配性（这个数字/开关挡不挡用户） | 源根可配，但配错后界面不告诉你配错了；只能看空列表 |

## 五、引用类比不成立

`editor-asset-browser` 的容错是「未知扩展名 → kind=file，仍然列出该文件」；本设计是「已知程序集 → 不产条目，且源文件也找不到时一条都不产」。前者是降级显示，后者是资产消失，不能拿前者为后者辩护。

## 六、验收反而保护了缺陷

`tasks.md:21` 的红态：

> 红态：源根空→源条目空不报错

这条把「源根空不报错」写成了必须通过的行为；`spec.md:29` 也写成 MUST NOT 报错。于是实现只要按设计做，验收就是绿的，用户拿到的是「程序集消失且无解释」。

## 七、结论与建议

- blocking。建议（不放松判据、不加魔数）：
  1. 源根不存在 = 配置错误，走显式失败或至少显式告警（例如 list-assets 仍 ok，但在条目/事件里带 `sourceRootMissing` 标记，或回一条 warning 级协议消息）；「源根存在但为空」才允许 ok 空列表。
  2. 隐藏程序集条目必须附可见说明（例如保留 shLib 条目并标注「源根缺失/由源文件替代」，或在 UI 上显示「已隐藏程序集条目，原因：…」），并给恢复开关（env 或 UI 动作）。
  3. 验收加一条：源根不存在时 MUST 有可读的缺失标记/日志（不能只断言「不报错」），且该标记能指出期望的源根路径。
