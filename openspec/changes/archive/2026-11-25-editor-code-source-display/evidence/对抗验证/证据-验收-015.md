## 3. 为什么这是执行缺口

- 要把浏览器指到临时根，必须设 `CASCADED_EDITOR_ASSET_ROOT=<temp>/CAAssets`；该覆盖在 `ScanSourceDirectory` 之后生效，因此导入器写 shLib 的目标仍是默认根，临时根里的 shLib 必须人工预置（3.2 没写谁预置、字节多少）。
- 源根按「资源根上级」或 `CASCADED_EDITOR_PROJECT_ROOT` 解析（design D4），3.2 没写用哪个；若用上级约定，临时根下必须有 `CAResources/Shaders`、`Scripting` 两个目录与夹具文件。
- 不写这些，执行者可以直接打开默认根（真实 CAAssets 有两条 shLib、真实源根有 16 份 .slang 与 38 份 .cs）并截到「有 .slang 行、没有 shLib 行」的图——与本 change 约定的临时夹具不是同一条，复核者无法从截图区分。
