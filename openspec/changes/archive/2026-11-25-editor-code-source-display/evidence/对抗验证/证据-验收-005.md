# 证据-验收-005：38 个 .cs 含 2 个构建产物

## 1. 工作区 38、git 跟踪 36（命令 + 真实输出）

```powershell
Write-Output ('工作区 Scripting 下 .cs 数: ' + (Get-ChildItem 'Scripting' -Recurse -Filter *.cs -File | Measure-Object).Count)
Write-Output ('git 跟踪的 Scripting 下 .cs 数: ' + ((git ls-files 'Scripting' | Where-Object { $_ -like '*.cs' }).Count))
git status --porcelain --ignored 'Scripting/Managed/obj'
Get-ChildItem 'Scripting/Managed/obj' -Recurse -Filter *.cs -File | ForEach-Object { 'obj 产物: ' + $_.Name + '  ' + $_.Length + ' B' }
```

真实输出：

```text
工作区 Scripting 下 .cs 数: 38
git 跟踪的 Scripting 下 .cs 数: 36
!! Scripting/Managed/obj/
obj 产物: .NETCoreApp,Version=v8.0.AssemblyAttributes.cs  198 B
obj 产物: Scripting.Managed.AssemblyInfo.cs  1025 B
```

`!!` 是 git 的 ignored 标记：`Scripting/Managed/obj/` 整个目录被忽略，两份 .cs 是构建生成的，不在版本库里。

## 2. 工件把 38 写成源文件总数（命令 + 真实输出）

```powershell
Select-String -Path 'openspec/changes/editor-code-source-display/proposal.md','openspec/changes/editor-code-source-display/design.md' -Pattern '38 个 \.cs|38 个' | ForEach-Object { $_.Filename + ':' + $_.LineNumber + ': ' + $_.Line.Trim() }
```

真实输出：

```text
proposal.md:31: - **依赖**：复用 IDisplayProvider/AssetEntry/AssetContext（editor-asset-browser）；源目录约定 CAResources/Shaders（16 .slang）/ Scripting（38 个 .cs）。
design.md:9: …由 `Scripting/` 下 **38 个 .cs** 编译来；无 csharp-script 资产种类。
```

## 3. provider 的扫描口径没有排除规则（逐字引文）

specs/editor-code-source-display/spec.md:33：「该提供者 MUST NOT 产 dll 条目，MUST 扫 `Scripting/`（env `CASCADED_EDITOR_CSHARP_SOURCE_ROOT` 可配）递归 `*.cs` 产每个源文件一条（kind=csharp-source…）」。tasks.md 2.2 同口径，均未提 obj/bin。

## 4. 后果

- 清洁检出（未构建）：`Scripting` 下 .cs = 36；构建后 = 38。写死任一个都会在另一种状态下红，红的原因与产品行为无关。
- 视觉验收用真实根时，`Scripting/Managed/obj/Debug/net8.0/Scripting.Managed.AssemblyInfo.cs` 等生成文件会作为「C# 源文件」出现在 dock 里。
