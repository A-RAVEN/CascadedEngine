# 证据-溯源-002：38 份 .cs 含 2 份构建生成物，dll 的真实编译输入还在 Scripting 之外

> 定位以逐字引文为准；行号是 2026-11-25 审查时实测值。

## 一、主张摘要

- 主张编号：主张-溯源-002（面① 数字溯源）
- 攻击面：无中生有
- 严重度：misleading
- 工件：`design.md:9`、`tasks.md:16`、`spec.md`（C# 源目录）
- 一句话：38 是目录里的全部 .cs，不等于「编译成 dll 的源」；其中 2 份是 obj 生成物，另有 128 份生成绑定在 Scripting 之外。

## 二、工件原文

`design.md:9`：

> C# 程序集 `Scripting.Managed.dll` 在 `out/build/<preset>/bin/`（**不在 CAAssets**），由 `Scripting/` 下 **38 个 .cs** 编译来。

`tasks.md:16`：

> 扫 Scripting/（env `CASCADED_EDITOR_CSHARP_SOURCE_ROOT`）递归 *.cs 产源条目

## 三、命令与真实输出

```powershell
PS> (Get-ChildItem Scripting -Recurse -Filter *.cs -File).Count
38
PS> (Get-ChildItem Scripting -Recurse -Filter *.cs -File | Where-Object { $_.FullName -match '\\obj\\' }).Count
2
PS> (Get-ChildItem Scripting -Recurse -Filter *.cs -File | Where-Object { $_.FullName -notmatch '\\obj\\|\\bin\\' }).Count
36
```

2 份 obj 生成物：

```text
Scripting\Managed\obj\Debug\net8.0\.NETCoreApp,Version=v8.0.AssemblyAttributes.cs
Scripting\Managed\obj\Debug\net8.0\Scripting.Managed.AssemblyInfo.cs
```

dll 还包含 `Scripting/` 之外显式 Include 的生成绑定（`Scripting/Managed/Scripting.Managed.csproj:44` / `:56`）：

```xml
<CascadedBindingFile Include="$(CascadedBindingDir)\*.Bindings.cs" />
...
<Compile Include="@(CascadedBindingFile)" />
```

```powershell
PS> (Get-ChildItem out\build\x64-debug\codegen\bindings -Filter '*.Bindings.cs' -File).Count
128
```

因此：手写源 36 份 + 生成绑定 128 份 = 实际编译输入 164 份；38 = 36 + 2 份 obj 生成物。`tasks.md:16` 递归扫 `Scripting/` 会把 `obj/` 里的两份生成物当成 csharp-source 列出来，同时 128 份真实输入完全不在扫描范围。

## 四、结论与建议

- 数字 38 作为「Scripting 目录下 .cs 数量」可核；但写成「由 Scripting/ 下 38 个 .cs 编译来」不准确：既多算了 2 份生成物，又少算了 128 份外部生成绑定。
- 这与另一面（`主张-存在-001`）指出的「dll 源不止 Scripting/」是同一根因；建议本面与存在面合并处置：源根约定要么扩成「手写源 + 生成绑定根」，要么在工件里明确「本批只显示手写源，生成绑定 128 份不在显示范围」并给出标记/恢复方式（否则是静默少给）。
- 递归扫 `Scripting/` 时必须排除 `obj/`、`bin/`（当前工件没写排除规则），否则会把 `AssemblyInfo.cs` 这类生成物当源显示。

## 五、边界

- 核了：38/36/2/128 的计数、obj 两份文件名、csproj 的 Include 行、bindings 目录非递归通配。
- 没核：没有实际跑 `dotnet build` 核对编译输入清单（只读环境，不跑构建）；「obj 两份不参与编译」依据 .NET SDK 默认排除 obj/bin 的规则与文件性质，未用编译日志二次验证。
