## 四、附：design 的行号锚点错位（顺带核出，不单列主张）

`design.md:7`：

> 浏览器枚举（`EditorService.ExecuteListAssets`，:1100-1134）

实际 `:1100-1134` 的枚举循环在 `EditorService.EnumerateAssets`（方法声明在 :1076），`ExecuteListAssets` 在 :1020、只是 :1024 调 `EnumerateAssets`。方法名与行号对不上：按行号能找到代码，按方法名会找到调用方。建议按项目规则改成「文件 + 逐字引文」（例如引 `Directory.EnumerateFiles(root, "*", SearchOption.AllDirectories)`），不要写行号。

- 行号锚点错位属可修的小问题：改成逐字引文即可；不影响 apply 的实现位置（EnumerateAssets 是唯一枚举点）。
