csharp-native-direct-binding 6.2 ABI v9 → v10 与重锚记录（2026-11-09）
=====================================================================

一、常量单点 + 布局重建
----------------------
1) `Tools/CodeGen/CodeGenMain.cpp`（生成的唯一来源，手写侧不保留第二份常量）：
   · `kEngineApiVersion` 9u → **10u**（单点 +1）；`kEngineApiSize` 80u → **56u**；
   · `kEngineApiFields[]` 删除桥五类的五个 `*_interface_id` 字段，剩 **9 个字段**：
     abi_version / size / log / echo / get_interface_api / window_interface_id /
     window_system_interface_id / get_binding_layout_type / get_binding_layout_field；
   · `static_assert(sizeof(EngineApi) == 56u)`（布局：4 + 4 + 8×5 + 4 + 4 = 56，
     8 字节对齐无尾部填充）；
   · 托管镜像同一次生成：`AbiVersion = 10`、`Size = 56`（`EngineApiMirror` 9 字段）。
2) 生成物实测（out/build/x64-debug/codegen/bindings/BindingRegistry.Bindings.h）：
     inline constexpr uint32_t kEngineApiVersion = 10u;
     inline constexpr uint32_t kEngineApiSize = 56u;
     static_assert(sizeof(EngineApi) == 56u, "生成的 EngineApi 必须是 56 字节（9 字段：4 + 4 + 8×5 + 4 + 4）");
     static_assert(kEngineApiSize == 56u, "kEngineApiSize 必须与 sizeof(EngineApi) 一致");
   `Host.cs` 的 Boot 用生成常量做两侧版本 / 大小比对，运行时自检同步生效。
