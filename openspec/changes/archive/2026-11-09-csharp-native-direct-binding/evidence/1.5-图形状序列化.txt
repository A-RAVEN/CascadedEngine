1.5 图形状序列化（design D11）—— 三类元素的红态、绿态与判据

执行者：apply 子 agent　　时间：2026-11-09 00:35 – 01:1x

一、任务与设计口径

design D11：序列化块元素扩三类（记录嵌套内任意深度生效）：
  ① 值类容器元素：`vector<CA_BIND_VALUE 值类>` —— 元素按四字段线形 kind/handle/nameptr/len 逐个重复；
  ② 命名映射成员：键固定 `cacore::NameHash` 的 map，值限标量/枚举/记录/值类 —— count + 重复(key 线形, value 线形)；
  ③ 接口对象引用成员：`shared_ptr<已挂 CA_BIND 接口>` —— u64 句柄过界，C++ thunk 从绑定对象表反查重建。
MUST NOT（不放松）：键非 NameHash 的映射、指向未绑定类型的智能指针、返回位置的映射容器 ⇒ 生成期点名拒绝，不静默丢字段。
另附一类真实头必需、D11 正文未单列的包装成员：`cacore::HashObj<T>`（`HashObj<ViewRectData> m_ViewPort`）——
线形 = 内层记录字段逐项，读回时重新包成 HashObj（实测 `DrawCallBatch::VertexInputDescMap` 的值就是这个形态）。

夹具（Tools/CodeGen/BindableShapes.NativeShapes.h）：记录 `GraphLikeRecord` 把三类元素收在一张表里：
    castl::vector<NativeResourceRef> m_Refs;                                        // ①
    castl::unordered_map<cacore::NameHash, uint32_t> m_Counts;                      // ② 标量值
    castl::unordered_map<cacore::NameHash, PassAttachment> m_Attachments;           // ② 记录值
    castl::unordered_map<cacore::NameHash, NativeResourceRef> m_RefsByName;         // ② 值类值
    castl::shared_ptr<IBindNativeShape> m_Object;                                   // ③ 直接成员
    castl::unordered_map<cacore::NameHash, castl::shared_ptr<IBindNativeShape>> m_Objects;  // ③ 映射值
方法：`virtual void ConsumeGraphShape(GraphLikeRecord const& shape) = 0;`

2) 托管镜像（GraphLikeRecord.Bindings.cs 逐字）：

5) 未支持类别的生成期点名（当前生成器实跑，退出码 1）：

    —— design D11 只定义 NameHash 键的命名映射；键非 NameHash 的映射容器维持不可绑（不静默丢字段）
   （夹具用 `std::unordered_map` 保持自包含：拒绝探针的 include 集不含 CASTL 的间接依赖 sha256.h。）

四、MUST NOT 的另一半：返回位置的记录不许含这三类字段（生成期拒绝，代码点可核）

`serializedFieldNeedsBindingTable()` 递归扫字段（含嵌套/元素/映射值），命中 kind 5/6 或 elementKind 4 时，
若该记录同时是"返回位置（D8 记录两段式）的载体"则拒绝，原文模板：
    记录 <名> 是返回位置（记录两段式）的载体，但字段 <字段> 是值类容器 / 命名映射 / 接口对象引用
    —— design D11 的 MUST NOT：返回位置的这些形状维持不可绑（不静默丢字段）
这条守的是"不静默丢字段"：这类记录的 C++ Serialize 不产写路径（生成物里是注释），若放任它们进返回位置，
托管读方向就会拿到缺字段的块。

五、判据（Tools/CodeGen/check_bindings.py 新增，全部是会失败的断言）

  · C ABI `ConsumeGraphShape` 两段字节声明逐字；
  · 托管表面 `public void ConsumeGraphShape(GraphLikeRecord shape)`；
  · `GraphLikeRecord.Bindings.cs` 六个镜像字段的逐字类型（数组 / Dictionary / 接口表面类）；
  · 托管写线形的四条逐字行（值类元素、值类值、接口引用映射值、接口引用直接成员）；
  · `GraphLikeRecord.BindingCodec.h` 里 `BindingHandleResolver resolver`、`reader.resolver.resolve`、`return 12u;`；
  · 产物里必须有 `ERROR_BAD_OBJECT_HANDLE`（1011）。
  · 错误码表同步：`ERROR_CODE_TABLE` 加 `1011: "BAD_OBJECT_HANDLE"`。
