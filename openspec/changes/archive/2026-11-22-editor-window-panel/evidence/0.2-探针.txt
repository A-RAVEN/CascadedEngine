读数字段含义：
  state=ok            探针走完整条链路（环境创建 → 控制器创建 → 导航 data URL 完成）
  mode=main-thread    WebView2 控制器建在**引擎主线程**，消息由 glfwPollEvents（UpdateSystem）泵
  controller=1 / nav=1 控制器创建成功 / NavigationCompleted 成功
  hwnd=0x...          父窗口句柄（由 GetNativeWindowHandle 的 HWND* 解引用得到）
  winBefore/winAfter  探针建窗前后的窗口计数（+1 = 只建了一个原生窗口）
  ticks              探针跨了多少次 Tick（vulkan 22 / d3d12 17，说明不是靠阻塞主线程同步等出来的）

----------------------------------------------------------------
4. D2 结论（实测决定，不预设）
----------------------------------------------------------------
**两个后端都是 mode=main-thread**：glfwPollEvents 是线程级消息泵（PeekMessageW(&msg,NULL,...)
全队列 DispatchMessage，0.1② 已核实），足以承载 WebView2 环境/控制器创建与导航。
⇒ D2 采用**主线程路径**：控制器在引擎主线程创建、Bounds/Navigate/Close 都在主线程调用；
  不需要专用 STA UI 线程。
探针里保留的 fallback 分支（专用 STA 线程 + 自己的消息泵）本次未被触发，仅作防御性代码保留到
1.6 后的清理点（1.6 用正式 Editor 服务替换探针时一并删除）。

----------------------------------------------------------------
5. 与 1.6 的衔接（由本读数确定）
----------------------------------------------------------------
- 控制器清理必须用 `Close()`（构建期实测 CS1061 的结论），不能用 Dispose。
- 控制器创建/导航都在主线程 Tick 内推进（异步任务 + 每帧轮询 IsCompleted），不得阻塞主线程等待。
- 子 HWND 的父句柄取法：`IWindow.GetNativeWindowHandle()` 返回的是 `&m_Win32Window`（HWND*），
  必须 `Marshal.ReadIntPtr` 解引用一次；直接把返回的 IntPtr 当 HWND 会创建失败。
