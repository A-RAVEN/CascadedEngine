## 回传通道 dry-run（固定四元组，脱离浏览器可复跑）

做法：由 `build.py` 的 `_env_for_root` 不参与，这里只用 Node 22 的 `--experimental-strip-types` 直接 import
`EditorWeb/src/spikeChannel.ts`（纯逻辑、无 DOM），构造与原生同一版式的固定帧（frame=7、背景绿、中心红三角、
四角标记、帧序号位），走 `decodeBase64 → buildReport`，打印四元组。脚本落在 `%TEMP%`、跑完即删。
逐字命令与输出：

```powershell
# 脚本内容见下方代码块，保存为 %TEMP%\spike-dryrun\dryrun.mjs
node --experimental-strip-types %TEMP%\spike-dryrun\dryrun.mjs
```

```js
import { buildReport, decodeBase64, fnv1a32, CANVAS_SIZE } from 'file:///E:/Projects/CascadedEngine/EditorWeb/src/spikeChannel.ts';
// ① 独立核对哈希算法：FNV-1a("abc") 的公认值是 0x1a47e90b。
console.log(`fnv1a32("abc")=${fnv1a32(new Uint8Array([0x61,0x62,0x63]))}（期望 1a47e90b）`);
// ② 与 C++ 同一版式的固定特征图案（frame=7）。
const size = CANVAS_SIZE, frame = 7, px = new Uint8Array(size*size*4);
const setPx=(x,y,r,g,b)=>{const o=(y*size+x)*4;px[o]=r;px[o+1]=g;px[o+2]=b;px[o+3]=255;};
for(let y=0;y<size;++y)for(let x=0;x<size;++x)setPx(x,y,0,255,0);
for(let y=64;y<=191;++y){const t=(y-64)/128,half=Math.floor(64*t+0.5);for(let x=128-half;x<=128+half;++x)setPx(x,y,255,0,0);}
for(const [x0,y0] of [[4,4],[244,4],[4,244],[244,244]])for(let y=y0;y<y0+8;++y)for(let x=x0;x<x0+8;++x)setPx(x,y,255,0,0);
for(let bit=0;bit<16;++bit){const on=((frame>>(15-bit))&1)===1;for(let y=4;y<12;++y)for(let x=32+bit*8;x<32+bit*8+8;++x)setPx(x,y,on?255:0,on?255:0,on?255:0);}
// ③ 帧 → base64 → 解码 → buildReport（与网页收到帧后的路径同一套函数）。
const base64 = Buffer.from(px).toString('base64');
const decoded = decodeBase64(base64);
const canvas = { width:256, height:256, rectX:16, rectY:178, rectWidth:256, rectHeight:256, visibility:'visible', display:'block' };
const report = buildReport({ frame, width:256, height:256 }, canvas, decoded, 1, 1);
console.log(`基站字节=${px.length} base64=${base64.length} 解码字节=${decoded.length}`);
console.log(`四元组 frame=${report.frame} hash=${report.hash} canvas=${report.canvasWidth}x${report.canvasHeight} rect=${report.rectWidth}x${report.rectHeight} display=${report.display} visibility=${report.visibility}`);
for (const s of report.samples) console.log(`  采样 ${s.name} (${s.x},${s.y}) = (${s.r},${s.g},${s.b},${s.a})`);
```

## 页面行为约束的落地（design D4）

- **禁止本地绘制**：`spike.ts` 的唯一绘制调用是 `context.putImageData(...)`（收到的帧原样上屏）；
  唯一的 `fillRect` 在 `?selftest=local-red` 分支里，只用来构造"网页本地画红"红态（`3.1-红态-local.json` 已被
  `E_WEBCANVAS_MISMATCH` 识破）。
- **回传字段**：`frame` / `width` / `height` / `canvasWidth` / `canvasHeight` / `rectX` / `rectY` /
  `rectWidth` / `rectHeight` / `visibility` / `display` / `hash` / `hashAlgorithm` / `webgpu` /
  `devicePixelRatio` / `samples[]`（七点），缺任一项 C# 侧形状校验就回 `E_BAD_MESSAGE`（`PROTOCOL.md` §7）。
- **自检开关**：`?selftest=hide-canvas`（`display:none`）、`?selftest=local-red`（本地画红）、
  `?selftest=no-line`（照收帧但不回传）。URL 查询串由托管侧按 `CASCADED_EDITOR_SPIKE_SELFTEST` 拼。

## 结论

1.2 三项验收全部满足：产物里有 `dist/spike.html`（3512B）、页面含 `<canvas>`、回传通道 dry-run 给出固定四元组
（frame=7 / hash=1a9ea5c5 / canvas=256×256 / 七点采样）。
