## 三、外部文档

### 3.1 `D3D11_RESOURCE_MISC_SHARED` 是 D3D11 的标志

Microsoft Learn `D3D11_RESOURCE_MISC_FLAG enumeration (d3d11.h)`：

- `D3D11_RESOURCE_MISC_SHARED = 0x2L`
- 原文：「Enables resource data sharing between two or more Direct3D devices. The only resources that can be shared are 2D non-mipmapped textures.」
- 原文：「This enumeration is used in D3D11_BUFFER_DESC, D3D11_TEXTURE1D_DESC, D3D11_TEXTURE2D_DESC, D3D11_TEXTURE3D_DESC.」
- 同一枚举里的 `D3D11_RESOURCE_MISC_SHARED_NTHANDLE = 0x800L`：「Set this flag to enable the use of NT HANDLE values when you create a shared resource.」

URL：<https://learn.microsoft.com/en-us/windows/win32/api/d3d11/ne-d3d11-d3d11_resource_misc_flag>

### 3.2 D3D12 资源描述没有 MiscFlags 字段

Microsoft Learn `D3D12_RESOURCE_DESC structure (d3d12.h)` 的字段是：

```text
D3D12_RESOURCE_DIMENSION Dimension;
UINT64                   Alignment;
UINT64                   Width;
UINT                     Height;
UINT16                   DepthOrArraySize;
UINT16                   MipLevels;
DXGI_FORMAT              Format;
DXGI_SAMPLE_DESC         SampleDesc;
D3D12_TEXTURE_LAYOUT     Layout;
D3D12_RESOURCE_FLAGS     Flags;
```

没有 `MiscFlags`。URL：<https://learn.microsoft.com/en-us/windows/win32/api/d3d12/ns-d3d12-d3d12_resource_desc>

### 3.3 D3D12 的共享机制是 `D3D12_HEAP_FLAG_SHARED` + `CreateSharedHandle`

Microsoft Learn `D3D12_HEAP_FLAGS enumeration (d3d12.h)`：

- `D3D12_HEAP_FLAG_SHARED = 0x1`
- 原文：「The heap is shared. Refer to Shared Heaps.」

URL：<https://learn.microsoft.com/en-us/windows/win32/api/d3d12/ne-d3d12-d3d12_heap_flags>

Microsoft Learn `Shared heaps`：

- 原文：「Both heaps and committed resources can be shared.」
- 原文：「Shared heaps are specified with the D3D12_HEAP_FLAG_SHARED member of the D3D12_HEAP_FLAGS enum.」
- 原文：「All methods are free-threaded and inherit the existing D3D11 semantics of the NT handle sharing design.」
- 同页列出的 API：`ID3D12Device::CreateSharedHandle`、`ID3D12Device::OpenSharedHandle`、`ID3D12Device::OpenSharedHandleByName`。

URL：<https://learn.microsoft.com/en-us/windows/win32/direct3d12/shared-heaps>

Microsoft Learn `ID3D12Device::CreateSharedHandle`：

- 原文：「Creates a shared handle to a heap, resource, or fence object.」
- `pObject` 支持 `ID3D12Heap` / `ID3D12Resource` / `ID3D12Fence`。
- 原文：「Both heaps and committed resources can be shared.」

URL：<https://learn.microsoft.com/en-us/windows/win32/api/d3d12/nf-d3d12-id3d12device-createsharedhandle>

### 3.4 结论

D3D11 的资源标志（`D3D11_RESOURCE_MISC_FLAG`）与 D3D12 的堆标志（`D3D12_HEAP_FLAGS`）分属两套 API；共享句柄是 `CreateSharedHandle` 的返回值，不是纹理描述的字段。工件把两者写成「`D3D11_RESOURCE_MISC_SHARED`（或 D3D12 shared handle）的纹理」，是把 D3D11 标志当成 D3D12 资源的共享方式，并把句柄当成纹理属性。按字面执行无法在 D3D12 后端产出共享纹理。

## 五、判定与修法

严重度：blocking（与存在面 `主张-存在-001.json` 同一处；父 agent 合并时只保留一条）。

修法（择一，写进 design D2 与 tasks 2.1）：

1. **走 D3D12 原生共享**：创建资源/堆时带 `D3D12_HEAP_FLAG_SHARED`（D3D12MA 路径上设 `ALLOCATION_DESC::ExtraHeapFlags = D3D12_HEAP_FLAG_SHARED`），再用 `ID3D12Device::CreateSharedHandle` 产出 NT 句柄；明确句柄不是纹理字段。
