## 二、API 真实存在，但在 C# 侧

`Scripting\Managed\Editor\EditorWindow.cs`：

调用者是 C# 的 `EditorWindow`，接收者 `m_EnvironmentTask.Result` 是 `CoreWebView2Environment`，参数 `Hwnd` 是 `internal IntPtr`。WebView2 包的 XML 文档里签名也在：

结论：API 真实，且工件写的 `(Hwnd)` 与仓库里的单参数用法一致。

## 四、现有唯一触发方式是被禁止复用的门控

`Scripting\Managed\Editor\EditorService.cs`：

```csharp
120:         internal static bool Enabled => Environment.GetEnvironmentVariable("CASCADED_EDITOR") == "1";
```

`Scripting\Managed\Host.cs`：

```csharp
307:                 if (s_system != null)
308:                 {
309:                     Editor.EditorService.Tick(s_system, s_renderBackend, s_renderTablesBound);
310:                 }
```

`Test\GPUBackendTester\Main.cpp` 的 `TestEditorWindowPanel`：

```cpp
4666: 	::SetEnvironmentVariableA("CASCADED_EDITOR", "1");
4667: 	::SetEnvironmentVariableA("CASCADED_EDITOR_PORT", "18391");
...
4670: 	auto newWindow = ctx.pWindowSystem->NewWindow(640, 480, "Editor Test Host Window");
```

也就是说：C++ 用例能建原生窗（`IWindowSystem::NewWindow`），但 WebView2 控制器是 C# `EditorWindow` 在 `EditorService` 里建的；C++ 用例只负责设环境变量和驱动 `IScriptHost`。这个入口正好是 `design.md` D1 明说“不复用”的 `EditorService` 一次性状态机。

再补一条创建点核对：`EditorWindow.Create` 全仓只有一个调用点，在 `Scripting\Managed\Editor\EditorService.cs`：

```csharp
427:             EditorWindow window = EditorWindow.Create(s_system, InitialWindowWidth, InitialWindowHeight,
428:                 s_panelWidth, s_dockHeight, navigationTarget, dockNavigationTarget, s_dataFolder, out string error);
```

`EditorWindow` 的构造函数是私有的（`Scripting\Managed\Editor\EditorWindow.cs` 的 `private EditorWindow(IWindow window, IntPtr hwnd, ...)`），外部只能走 `Create`；而 `Create` 只在 `EditorService` 里被调用。C++ 用例既不能直接构造 `EditorWindow`，也没有别的路径能走到 `CreateCoreWebView2ControllerAsync`。

`design.md` D1 确实留了另一条路：“或独立门控开关起原型窗”。但 `tasks.md` 2.2 选的是“tester 用例”这条，且没有点名新增哪个托管入口/门控、由谁把 `Hwnd` 交给 `CreateCoreWebView2ControllerAsync`。按任务字面只改 `Main.cpp`，`CreateCoreWebView2ControllerAsync` 不会被任何 C++ 代码调用到。

## 五、本面结论

- `CreateCoreWebView2ControllerAsync(Hwnd)` 真实存在，仓库里的用法是 C# 的 `CoreWebView2Environment` 方法。
- 全仓 C++ 对 WebView2/CoreWebView2 零调用；C++ 的 `TestWebRenderSpike` 不能直接创建控制器。
- 现有唯一触发路径是 `CASCADED_EDITOR=1` 门控进 `EditorService`，被本 change 禁止复用。
- `design.md` D1 提到“或独立门控开关”，但 `tasks.md` 2.2 没点名新的托管入口/门控与 `Hwnd` 传递方式；按任务字面实现会卡在这里。
- 以上合并成 `主张-存在-002.json`。
