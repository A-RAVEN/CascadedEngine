# 证据-影响-006：design D2 把 D3D11 与 D3D12 两套共享方式写成「或」

对应主张：`主张-影响-006.json`（严重度 misleading）。

## 1. 工件原文（逐字）

`openspec/changes/editor-web-render-spike/design.md` 第 25 行：

> 复用 D3D12 后端渲染确定性画面（红三角或纯色，沿用现有探针）。渲染目标是一张带 `D3D11_RESOURCE_MISC_SHARED`（或 D3D12 shared handle）的纹理，产出共享句柄。画面尺寸/像素期望写死（正控）。

`openspec/changes/editor-web-render-spike/tasks.md` 第 14 行：

> 渲染目标带共享句柄（D3D11_RESOURCE_MISC_SHARED / D3D12 shared handle）

## 2. 代码原文（逐字）

`D3D12RenderBackend/private/ResourceManagment/MemoryManager.cpp:41-54`（D3D12 资源创建只认 `D3D12_RESOURCE_DESC` 与 `D3D12MA::ALLOCATION_DESC`，没有 D3D11 标志的位置）：

```cpp
	GPUResource MemoryManager::AllocGPUResource(D3D12_RESOURCE_DESC const& resourceDesc, D3D12_HEAP_TYPE heapType)
	{
		D3D12_RESOURCE_ALLOCATION_INFO allocationInfo = GetDevice()->GetResourceAllocationInfo(0, 1, &resourceDesc);
		D3D12MA::ALLOCATION_DESC allocationDesc = {};
		allocationDesc.HeapType = D3D12_HEAP_TYPE_DEFAULT;

		D3D12MA::Allocation* allocation;
		HRESULT hr = m_Allocator->CreateResource(
			&allocationDesc,
			&resourceDesc,
			D3D12_RESOURCE_STATE_COMMON,
			NULL,
			&allocation,
			IID_NULL, NULL);
```

## 4. 影响

- `D3D11_RESOURCE_MISC_SHARED` 是 D3D11 资源创建标志；D3D12 设备创建的纹理走 `D3D12_RESOURCE_DESC`，没有这一位，D3D12 的对应物是 `D3D12_HEAP_FLAG_SHARED` + `ID3D12Resource::CreateSharedHandle`（或 D3D11 侧以 `MISC_SHARED_NTHANDLE` 建资源、D3D12 侧 `OpenSharedHandle` 打开）。
- 本仓库只有 D3D12 后端（D3D11 相关代码 0 命中），没有 D3D11 设备可供跨 API 使用；把两种写法写成「或」，实现者按字面会在 D3D12 资源描述上找不到这个标志，或被迫在 spike 里新建一个 D3D11 设备——那是工件没有授权、也没有验收的新增面（适配器选择、跨设备同步、生命周期都要重做）。
- 这条与主张-影响-004 叠加：不只「共享句柄没有实现」，连「用哪套 API 实现」都还没定。

## 5. 建议的能失败判据

1. design D2 与 tasks 2.1 删掉「或」，写死一条：D3D12 堆 + `CreateSharedHandle`，**或** D3D11 设备 + `OpenSharedHandle`，二选一。
2. 写明设备/适配器、句柄生命周期与释放责任（谁 Create、谁 Close、在哪一帧之后可以关）。
3. 验收：`Select-String -Path 'openspec/changes/editor-web-render-spike/design.md','openspec/changes/editor-web-render-spike/tasks.md' -Pattern 'D3D11_RESOURCE_MISC_SHARED'` 命中数必须为 0；实现文件里 `CreateSharedHandle` 或 `OpenSharedHandle` 至少命中 1 处，且与 design 选定的那条一致。
