## 三条跨面结论（按修复优先级）

1. **两条判据可以同时绿而核心命题为假。** 兜底路径「一定能跑通」（design.md:34）+ 期望是常量 + 没有同源绑定，三条合起来使「原生渲染进网页」这件事在本工件里不可证伪。最小修复顺序：010（整图哈希 + 帧序号对账）→ 008（读回绑共享纹理）→ 003（禁止页面本地画红）。
2. **「可核」是工件的系统性软词。** 全文 8 处「可核」，每处都没有写「判什么值、什么失败码、红态怎么造」：2.1 共享句柄（011）、1.2 像素回传通道（002）、3.1 红态（004）、4.2 结论（012）。建议整体替换，而不是逐处补一句。
3. **红态无法由第三方复跑。** 工件 0 处自检开关、0 处超时、0 处 `E_XXX` 失败码；归档批次 `2026-11-24-editor-asset-browser/evidence/4.1-首次运行红态.txt` 有现成格式（退出码 + status + error 原文）与注入惯例（`CASCADED_*_SELFTEST` 环境变量），照抄即可。
