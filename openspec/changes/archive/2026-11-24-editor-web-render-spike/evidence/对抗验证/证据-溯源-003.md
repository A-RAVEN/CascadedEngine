## 四、中心像素判据无法区分三角形/纯色/1×1

### 4.1 判据只有中心点

`tasks.md:14` 的验收是「离屏读回中心 == (255,0,0,255)」；`tasks.md:20` 的 3.1 是「网页 canvas 中心像素 ... == (255,0,0,255)」；`spec.md:10` 的 THEN 也是「中心像素 MUST == (255,0,0,255)」。三处都没有第二个采样点。

一个 1×1 纯红纹理的「中心」就是它自己，读回 `(255,0,0,255)` 通过；整张纯红填充的中心也是红的，通过。3.1 的反例只列「原生未渲染/互操作断链 → canvas 空白/黑」，纯红/1×1 不属于这两个反例，所以不会红。

### 4.2 现有探针的对照

`Test/GPUBackendTester/Main.cpp:2347-2349`（`TestCSharpTriangle`）：

```cpp
const std::array<uint8_t, 4> expectedBackground{ 0, 255, 0, 255 };
const std::array<uint8_t, 4> expectedCenter{ 255, 0, 0, 255 };
if (differs(background, expectedBackground) || differs(center, expectedCenter))
```

这条判据同时读背景 `(0,255,0,255)` 与中心 `(255,0,0,255)`，纯红填充会在背景点红（背景不是绿色），所以能区分纯色与红三角。

`Test/GPUBackendTester/Main.cpp:4614-4615`（`ReadCaptureCenterRed`，`TestEditorWindowPanel` 调用）：

```cpp
// 判据（工件修订：与既有探针一致的精确像素，不放宽）：离屏捕获中心必须精确是三角形红。
return r == 255 && g == 0 && b == 0 && a == 255;
```

它只判中心；`TestEditorWindowPanel` 的 ⑩ backbuffer 回读（`Main.cpp:5534`、`:5599`）也只判中心。也就是说，现有探针里**既有**能区分纯色与三角形的双点判据（`TestCSharpTriangle`），也有只判中心的单点判据（`TestEditorWindowPanel`）；spike 的 tasks 2.1/3.1 只要求中心，没有说明用哪一种，也没有要求背景/第二点。

### 4.3 3.2 是唯一形状检查，但没有几何期望

`tasks.md:21` 的 3.2 用 `read_image` 核对「原生红三角」。这是唯一能看形状的检查，但：

- 没有写死期望尺寸/几何（多宽、多高、三角形占多少）；
- design.md:25 明说可用「纯色」，纯红矩形在 3.2 里不是「红三角」，但 3.1 已经绿了；
- 如果执行者按 design 的「或纯色」实现，3.2 的「红三角」措辞就与 design 冲突；如果按 tasks 的「红三角」实现，design 的「或纯色」就是空话。

同一份工件对「是否必须是三角形」自相矛盾，且「画面尺寸写死」没有数字。

## 五、判定与修法

严重度：misleading（3.1 可以在退化实现上绿；3.2 的人眼检查是最后一道，但没有几何期望，且 design 允许纯色）。

修法：

1. **写死尺寸**：从现有探针读数行取一个可追溯的值（例如 `Main.cpp:7270` 的 `320x240`，或 `TestEditorWindowPanel` 的 capture 尺寸），写进 design D2 与 tasks 2.1；或做成配置项并在配置表登记默认值与范围。不要凭空取数。
2. **明确三角形还是纯色**：若保留「红三角」，删掉 design 的「或纯色」，并在 3.1 加背景采样（沿用 `TestCSharpTriangle` 的 `(0,255,0,255)`）或第二个采样点，使纯红填充必红；若接受纯色，改 spec 场景与 tasks 3.2 的「红三角」措辞，并说明为什么纯色足以证明「原生画面进网页」。
3. **红态加退化对照**：同一进程分别渲染「1×1 纯红」「整张纯红填充」「红三角」，前两者 3.1 必须红（或 3.2 必须判不通过），第三者绿；evidence 存三次的 result.json/截图。
4. **3.2 写死期望几何**：至少写死 canvas 的 CSS 尺寸与三角形的大致区域（例如「中心行红色像素宽度 > 画布宽度的 1/4」），或者让 3.1 直接判两个采样点，不依赖人眼。
