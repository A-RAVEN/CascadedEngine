## 三、两个候选的设施都不在工件覆盖范围

WebSocket 服务端只在 EditorService（逐字，`EditorService.cs`）：

> 225：`s_listener = new HttpListener();`
>
> 1230：`private static void HandleContext(HttpListenerContext context)`
>
> 1247：`private static void AcceptWebSocket(HttpListenerContext context)`

而 spec 要求 1 明写「spike MUST NOT 复用 EditorService 一次性状态机」。host object 路径的全仓命中：

```text
PS> Get-ChildItem -Recurse -Include *.cs,*.cpp,*.h -File |
     Where-Object { $_.FullName -notmatch '\\out\\|\\_deps\\' } |
     Select-String -Pattern 'AddHostObjectToScript'
命中=0
```

现有编辑器的两个 WebView2 控制器从未用过 host object，所以这条路同样是新设施。

## 四、结论与改法

一条正控判据（3.1 的 canvas 中心像素）依赖一条尚未选型、也没有归属任务的回传通道；通道做不出来时，失败会表现为「拿不到像素」，无法区分是通道没通还是互操作没成。

改法：把通道选型写成 design 决策 + 一条独立任务，明确选 host object 还是 spike 自带 WebSocket、放哪个文件、失败打什么码；tasks 1.2 的验收改成「通道未建立时 3.1 红并打印 `E_SPIKE_CHANNEL`」。
