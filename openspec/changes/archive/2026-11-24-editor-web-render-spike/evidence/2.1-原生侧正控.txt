# 2.1 非绑定面 D3D12 共享纹理助手 —— 原生侧正控证据

## 实现位置（不碰绑定面）

| 文件 | 作用 |
|---|---|
| `Interface/RenderInterface/header/WebRenderSpike/IWebRenderSpike.h` | 非绑定面接口（`IWebRenderSpikeSharedTexture` / `IWebRenderSpikeProvider`）。**没有 CA_BIND 标注、不在 `build.py` 的 `CODEGEN_ANNOTATED` 里**，CodeGen 看不到它 |
| `D3D12RenderBackend/private/WebRenderSpike/D3D12WebRenderSpike.{h,cpp}` | 实现：共享堆纹理 + `CreateSharedHandle` + `OpenSharedHandle` 第二消费者 + 读回；自有 direct 队列/分配器/fence |
| `D3D12RenderBackend/private/RenderBackend_D3D12.cpp` | 只在这个 .cpp 里登记/注销 `D3D12WebRenderSpikeProvider`（实例名 `WebRenderSpike`），复用同一 `ID3D12Device`；**被 CodeGen 解析的 `RenderBackend_D3D12.h` 与 HEAD 逐字节一致** |

机制与文档依据（design D2）：
- 共享堆纹理：`D3D12_HEAP_FLAG_SHARED` 的 committed resource + `ID3D12Device::CreateSharedHandle`
  （[shared-heaps](https://learn.microsoft.com/en-us/windows/win32/direct3d12/shared-heaps)、
  [CreateSharedHandle](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/nf-d3d12-id3d12device-createsharedhandle)）。
- 资源标志 `ALLOW_RENDER_TARGET | ALLOW_SIMULTANEOUS_ACCESS`（[D3D12_RESOURCE_FLAGS](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/ne-d3d12-d3d12_resource_flags)）。
- 第二消费者：`ID3D12Device::OpenSharedHandle` 打开**同一个句柄**得到独立资源对象，再从它读回像素。
- 渲染复用后端设备（`RenderBackend_D3D12::GetDevice()`），提交走本类自己的 direct 队列；**不碰**
  `MemoryManager` 公共分配路径，也不改 `GPUTexture` 绑定面。

## 判据与失败码（`Test/GPUBackendTester/Main.cpp` 的 `TestWebRenderSpike`）

| 判据 | 失败码 |
|---|---|
| `CreateSharedHandle` 后句柄非空 | `E_SPIKE_SHARED_HANDLE` |
| 本设备读回成功 | `E_SPIKE_READBACK` |
| 背景绿 / 中心红 / 四角红 / 帧序号位（16 位二进制解码）全部匹配 | `E_SPIKE_PATTERN` |
| `OpenSharedHandle` 第二消费者读回成功 | `E_SPIKE_OPEN_SHARED_HANDLE` |
| 第二消费者读回字节与本设备读回**逐字节一致** | `E_SPIKE_SECOND_CONSUMER` |
| 帧 1 与帧 2 的整图哈希不同（帧序号真的进了像素） | `E_SPIKE_FRAME_BITS` |
