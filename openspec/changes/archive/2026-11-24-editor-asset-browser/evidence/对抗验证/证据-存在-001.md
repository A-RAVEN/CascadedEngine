## 二、本条主张展开：两处写法为什么不能照抄

### 1. 现句（逐字）

`design.md:52`：

```text
… `GetResourceRootPath()` 取根 → `Directory.EnumerateFiles(root, AllDirectories)` → 每文件 `FileInfo`（大小/修改时间）…
```

`tasks.md:17`：

```text
… GetResourceRootPath → Directory.EnumerateFiles(AllDirectories) → FileInfo 大小/时间 …
```

### 2. 反射读数（Windows PowerShell 5.1 / .NET Framework 4.0；项目 target net8.0）

```text
PS> [System.IO.Directory].GetMethods() | Where-Object { $_.Name -eq 'EnumerateFiles' } |
>>   ForEach-Object { ($_.GetParameters() | ForEach-Object { $_.ParameterType.FullName + ' ' + $_.Name }) -join ', ' }
System.String path, System.String searchPattern
System.String path, System.String searchPattern, System.IO.SearchOption searchOption
System.String path

PS> [bool]([System.IO.Directory].GetMethod('EnumerateFiles', [type[]]@([string],[System.IO.SearchOption])))
False
```

即：只有 `(path)`、`(path, searchPattern)`、`(path, searchPattern, SearchOption)` 三个重载；`(path, SearchOption)` 不存在。.NET 8 另有 `(path, searchPattern, EnumerationOptions)` 这一**三参**重载，仍没有 `(path, SearchOption)` 两参形态；照字面写会编译失败。

### 3. 类型名读数

```text
System.IO.DirectoryNotFoundException   => True
System.UnauthorizedAccessException     => True   （注意命名空间是 System，不是 System.IO）
System.IO.IOException                  => True
DirectoryNotFound                      => False
UnauthorizedAccess                     => False
```

design/tasks 的 `DirectoryNotFound` / `UnauthorizedAccess` 是简写，真实类型名各缺 `Exception`；同一句后半段又用了全名 `DirectoryNotFoundException`，前后不一致。

### 4. 影响与修法

- 这条不是设计意图错：design D3 要的是「递归枚举资源根」，正确形态是 `Directory.EnumerateFiles(root, "*", SearchOption.AllDirectories)`（或 `EnumerationOptions` 重载）。
- 如果实现者照 `design.md:52` / `tasks.md:17` 的形态抄，会先撞编译错误；这类「工件点名的接口形态不存在」属于误导级，不阻塞设计，但会让执行者多绕一步，也让 tasks 2.3 的「构建过」判据在第一次编译时不成立。
- 异常捕获面：tasks 2.3 已要求把 `DirectoryNotFound/UnauthorizedAccess/IOException` 转 `E_ASSET_ROOT`；改成全名后，`FileInfo.Length` / `FileInfo.LastWriteTimeUtc` 的读取也可能抛 `UnauthorizedAccessException` / `IOException`，与 design D3 的捕获面一起写清即可。
