## 为什么算矛盾（不是措辞问题）

1. **终态互斥**：同一份「唯一事实源」的同一段落不能既把资产浏览器叫「资产区」又叫「底部通栏 dock」；5.5 说「与右面板对象检查器分离」，而现行 §5 把这套控件绑在右面板的资产区上。
2. **已勾条目的判据失效**：5.2 的验收词是「§5 含资产区映射」；5.5 落地后这句必须被改写，5.2 的勾选就不再被任何现行判据支持（tasks.md 是唯一进度事实源，出现「已勾但判据已作废」的条目）。
3. **5.5 的 grep 可能恒真**：5.5 只写「§5 含 dock 映射（grep）」，没给期望字符串；若执行者 grep `list-assets`（5.2 已写入，现状即命中），无论 dock 措辞加没加都是绿。

## 建议修法

1. 二选一合并：把 5.2 的 PROTOCOL §5 验收词改成 dock 措辞（5.2 已勾，需按项目规则补改前/改后原文），5.5 删掉 PROTOCOL §5 那半句，只留 README 配置表与 docs/testing.md。
2. 给两条具体 grep 期望：`底部资产浏览器 dock` 当前 0 命中 → 改后 ≥1；`**资产区**（editor-asset-browser）` 改后 0 命中。
3. 修订记录里补一条「5.2/5.5 合并」，说明 5.2 的旧验收词作废依据（2026-11-24 用户布局裁定）。
