# 证据-溯源-004：「用户裁定」的可核性 + 静默降级面核查

## 一、17 号布局裁定：原话只在自述里

命令：

```powershell
Select-String -Path (Get-ChildItem -Recurse -Include *.md,*.txt,*.json -File | Where-Object { $_.FullName -notmatch '\\out\\|evidence\\对抗验证' }) -Pattern '不是在下侧','独立的栏','底部通栏独立 dock'
```

真实输出：

```text
「不是在下侧」 命中 1 处:
   openspec\changes\editor-asset-browser\tasks.md:77
「独立的栏」 命中 1 处:
   openspec\changes\editor-asset-browser\tasks.md:77
「底部通栏独立 dock」 命中 1 处（排除本轮 claim 后）:
   openspec\changes\editor-asset-browser\tasks.md:77
```

判据：仓库里除 tasks.md:77 这条修订记录本身，没有任何对话落盘、截图、证据文件记录用户的原话或选项。这条「用户裁定」在工件内部是自证。

同一条修订记录的末句却写得很清楚：

```text
tasks.md:79:…dock 高可配运行期固定为主循环依面板宽先例的默认选型（用户未选拖拽，留后续）；多窗自由 dock 由后续 dock 框架 change 做，本批独立面板单元是铺垫。
```

即：「底部通栏 dock」是用户裁定（据自述），「dock 高可配、运行期固定、不拖拽」是主循环自己按先例的选型。这半句没有把自选冒充用户要求——这一点站得住。

## 二、18 号截图纪律：可核

命令：

```powershell
Test-Path 'AGENTS.md'
Select-String -Path "$env:USERPROFILE\.dsh\AGENTS.md" -Pattern '阻碍我工作'
```

真实输出：

```text
False
C:\Users\76956\.dsh\AGENTS.md:32:- **编辑器相关开发任务必须截图视觉验收（…）**：…**截图不得干扰用户桌面（2026-11-24 用户明令「禁止前置窗口，阻碍我工作」）**：…抓窗用 `PrintWindow`（按 HWND 渲染窗内容，被其它窗挡住也能抓，不动前景）或 `capture.ps1 -Mode full` 抓屏幕现状…
```

判据：原话可逐字核到，但它在**工作区外**的全局 AGENTS.md；仓库根没有 AGENTS.md（`Test-Path` = False，只有 CLAUDE.md）。工件三处写「AGENTS §2」，读者在仓库里找不到这个文件，引用应补全路径。

另注：全局这条规则本身也把「PrintWindow…被挡也能抓」写成了事实——工件的说法是从这里继承的，不是工件自己新造；但它对被抓对象的适用性仍无实测（见 主张-溯源-003）。

## 三、静默降级面核查（五条里的第④条）

逐个看工件里所有「少给 / 截断 / 退化」分支：

| 分支 | 工件里的标记 | 判定 |
|---|---|---|
| `children` v1 恒空 | spec 要求 2 逐字「children MUST 为 v2 投影预留（v1 恒空）」；design D1/D2 同 | 已标记（但响应里没有机器可读的 v1/partial 标记，第三方客户端只能靠读 PROTOCOL 判断——记 minor 观察，不单独立条） |
| 无文件监听、无定时刷新 | design D5 逐字「v1 不做文件监听轮询（无定时器）——刷新由客户端驱动」 | 已标记 |
| 无分页、全量枚举 | design 风险节逐字「v1 全量枚举无分页；性能优化后续批，不预先发明上限数字」 | 已标记，且没有发明上限 |
| dock 高运行期固定、不拖拽 | proposal Non-goals、design D9、Open Questions 三处 | 已标记 |
| 门面未绑 / 根非法 / IO 错误 | E_ASSET_ROOT + spec 要求 4「MUST 显式报错…MUST NOT 静默返回空列表」 | 显式，不静默 |
| dock 高越界 | tasks 3.2 验收「超范围明确报错」；spec 要求 1 只写「范围」没写越界处置（指向 主张-溯源-002 第④点） | 部分标记 |

结论：**本面未发现 blocking 级静默降级**；减少内容的分支都写了「少给什么」。唯一没写的是 dock 高越界后到底禁用还是裁剪（已在 002 主张），以及 children 恒空在响应层无标记（minor，不影响本批 v1 1:1 语义）。
