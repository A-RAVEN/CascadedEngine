# 证据-溯源-001：no-runtime 自检覆盖不了「第二控制器创建失败」

## 一、工件原文

命令：

```powershell
Select-String -Path 'openspec/changes/editor-asset-browser/design.md' -Pattern '第二控制器创建失败'
Select-String -Path 'openspec/changes/editor-asset-browser/tasks.md' -Pattern 'no-runtime 自检覆盖'
```

真实输出（节选，原文逐字）：

```text
design.md:78:- 第二控制器创建失败 / 运行时缺失 MUST 明确报错并禁用编辑器（与既有控制器同处置，no-runtime 自检覆盖）；dock 静态资源（assets.html）缺失 MUST 明确错误页。
tasks.md:23:…第二控制器创建失败/运行时缺失明确报错禁用（no-runtime 自检覆盖），dock 静态资源缺失明确错误页。验收：…
```

括号里这句话把两种失败并列，并给出同一个覆盖来源「no-runtime 自检覆盖」。

## 二、no-runtime 自检的真实实现

命令：

```powershell
Select-String -Path 'Scripting/Managed/Editor/*.cs' -Pattern 'CASCADED_EDITOR_SELFTEST' -Context 3,3
```

真实输出（EditorWindow.cs，逐字）：

```text
60:        internal static EditorWindow Create(IWindowSystem system, int width, int height, int panelWidth,
61:            string navigationTarget, string dataFolder, out string error)
62:        {
63:            error = string.Empty;
64: #if DEBUG
65:            // M14（工件修订）：Debug 自检开关强制走"WebView2 运行时缺失"路径，供 TestEditorWindowPanel
66:            // 的 no-runtime 变体断言"明确禁用、进程不崩、错误文本可辨"。
67:            if (Environment.GetEnvironmentVariable("CASCADED_EDITOR_SELFTEST") == "no-runtime")
68:            {
69:                error = "WebView2 运行时缺失（自检开关 CASCADED_EDITOR_SELFTEST=no-runtime 模拟）";
70:                return null;
71:            }
72: #endif
73:            IWindow window;
```

判据：`return null` 发生在 `system.NewWindow(...)`（:76）**之前**。也就是说 no-runtime 时连原生窗口都不建，WebView2 环境与任何控制器更不会创建。它证明的是「运行时缺失 → 明确禁用」，不触碰「运行时正常、第二个控制器创建失败」这条分支。

## 三、全仓自检值清单（没有第二个开关）

命令：

```powershell
Select-String -Path (Get-ChildItem -Recurse -Include *.cs,*.md,*.cpp -File | Where-Object { $_.FullName -notmatch '\\out\\' }) -Pattern 'CASCADED_EDITOR_SELFTEST' | ForEach-Object { "$($_.Path.Replace((Get-Location).Path+'\','')):$($_.LineNumber): $($_.Line.Trim())" }
```

真实输出（去重后的取值面）：

```text
CSharpHost/README.md:121: …`CASCADED_EDITOR_SELFTEST=no-runtime`（仅 Debug：模拟 WebView2 运行时缺失 → 明确禁用、不崩）、`CASCADED_EDITOR_SELFTEST=no-facade`（跳过资源注册表门面绑定…）
CSharpHost/README.md:393:| `CASCADED_EDITOR_SELFTEST=no-runtime` | **仅 Debug**：模拟 WebView2 运行时缺失，验证"明确禁用、不崩"路径 | 不设 |
CSharpHost/README.md:394:| `CASCADED_EDITOR_SELFTEST=no-facade` | 资产浏览的门面未绑红态… | 不设 |
Scripting/Managed/Editor/EditorWindow.cs:67: if (Environment.GetEnvironmentVariable("CASCADED_EDITOR_SELFTEST") == "no-runtime")
```

只有 `no-runtime` 与 `no-facade` 两个值；没有任何值能让「第二个 WebView2 控制器创建失败」或「assets.html 静态资源缺失」变红。

## 四、该分支此刻的代码状态

`grep` 全仓 `DockHeight|DOCK_HEIGHT`（排除 out/）只在 change 工件里命中 8 处，代码与 README 配置表零命中 —— 第二控制器尚未实现，tasks 3.2/3.3 仍未勾。

命令：

```powershell
Select-String -Path (Get-ChildItem -Recurse -Include *.cs,*.md,*.cpp,*.ts,*.html -File | Where-Object { $_.FullName -notmatch '\\out\\' }) -Pattern 'DOCK_HEIGHT|DockHeight'
```

真实输出：8 行全部落在 `openspec/changes/editor-asset-browser/` 下的 design.md / proposal.md / tasks.md / 两份 spec，`Scripting/`、`CSharpHost/` 零命中。

## 五、结论

「（no-runtime 自检覆盖）」对「运行时缺失」为真，对「第二控制器创建失败」为假——后者在工件里是一条 MUST，却没有可构造的红态。这是把没有的验证能力写成已有的（无中生有）。
